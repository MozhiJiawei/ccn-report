# GSE：从局部修补走向全局可复用技能

## 一句话总结

GSE 让编码 Agent 在学习新经验时同时检查技能之间的依赖和冲突；在 2026 年 8 月 6 日发布的论文初版中，它在缺陷触发测试上兼顾查准率与查全率的综合分数达到 0.31 和 0.38，在误报过滤上达到 0.70 和 0.46，均优于论文采用的对比方案。

## 它解决什么问题

一个任务失败后，最直接的做法是新增一条规则。但规则越积越多，越容易互相矛盾：一条规则改变了输入，另一条规则却还在依赖旧输入；多条规则也可能只是同一种能力的不同写法。局部修补看似解决了眼前问题，长期却会让技能库碎片化，并损害以前已经具备的能力。

## 方案怎么做

这份报告提出 SkillMesh。它先用一张“技能关系图”记录技能之间的依赖、共同使用和冲突关系，再把多个相似案例合并成更通用的能力。每次更新不仅要重放产生问题的原案例，还要检查相关历史任务，确认没有带来新的退化，最后才把技能收入正式技能库。

业务试点建议把学习任务和验证任务完全分开，目标是在新任务上的成功率或综合得分至少提高 10%，历史任务退化不超过 2%，单任务模型输入量和耗时的增加不超过 15%。这些是业务验收目标，并非论文已经证明的产品效果。
