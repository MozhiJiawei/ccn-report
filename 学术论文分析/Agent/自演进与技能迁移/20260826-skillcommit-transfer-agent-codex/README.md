# SkillCommit：让失败经验成为可验证的技能

## 一句话总结

SkillCommit 帮助 Agent 平台把一次失败中学到的经验整理成可测试、可追踪、可撤回的技能；在 2026 年 8 月 15 日发布的论文初版中，它在航空规则和篮球规则两组实验里分别多解决了 24 个和 19 个问题，同时只新增了 0 个和 2 个错误。

## 它解决什么问题

很多 Agent 会把过去的对话或执行记录直接塞进下一次任务。这样虽然简单，却很容易误用经验：两个任务表面相似，真正需要遵守的规则却可能完全不同。结果往往是输入越来越长、成本越来越高，还可能把原本能做对的任务做错。

## 方案怎么做

这份报告提出在 OpenClaw 外围增加一层技能管理机制。系统先从失败中提炼出“什么时候适用、应该怎样修复、什么情况下不要使用”，再用原任务复测、相似任务验证和历史任务回归检查来决定是否收录。没有通过检查的经验只保留为单次修补，不会扩大使用范围；已经上线的技能也保留完整版本记录，可以快速退回旧版本。

业务试点建议用两组从未参与学习的新任务进行验证，目标是成功率至少提高 8 个百分点、模型输入量减少 35% 至 50%、误用经验造成的负面影响减少一半。以上是试点目标，不是论文已经证明的产品效果。
