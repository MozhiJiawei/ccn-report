# Agent 技能为什么有效，又为什么会失效

## 一句话总结

这项研究解释了 Agent 技能真正起作用的条件：在 2026 年 8 月发布的论文初版中，技能方案在 83 个可直接比较的任务上把成功率从直接复用历史记录时的 64.1% 提高到 69.6%，同时让模型少处理约 3.42 万个文本单位。

## 它解决什么问题

企业常把优秀 Agent 的历史执行记录当作“经验”重复使用，但原始记录里既有有效步骤，也有绕路、报错和只适用于当时环境的细节。记录越积越多，系统越难判断该用哪一条，甚至会在不合适的任务上主动介入，造成新的失败。

## 方案怎么做

这份报告提出 SkillFoundry，把原始执行记录加工成结构清楚的技能包。每个技能包都说明适用范围、使用前提、运行时检查方法、来源和版本，并保留自动撤回方案。候选技能不会因为在原任务上成功一次就直接上线，而是要在未参与学习的新任务上，与“不使用历史经验”和“直接复用原始记录”两种方式公平比较。

业务试点的目标是：新任务成功率比不使用历史经验至少提高 10 个百分点，模型处理的文本量比直接复用原始记录至少减少 20%，出现异常时自动撤回的成功率达到 95% 以上。这些指标仍需在真实业务中验证。
