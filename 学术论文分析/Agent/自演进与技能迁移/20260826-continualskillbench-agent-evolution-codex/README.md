# ContinualSkillBench：怎样证明 Agent 真的在持续进步

## 一句话总结

ContinualSkillBench 用约 3 万个任务检验 Agent 是否能够持续学习；2026 年 8 月 4 日发布的论文初版覆盖法律、金融、医疗、数学和办公五个领域，并分别比较“每次从零开始”和“按顺序积累经验”两种运行方式，为判断进步、遗忘和技能复用提供了统一尺度。

## 它解决什么问题

Agent 在看到更多历史记录后，当前任务的分数可能会上升，但这并不等于它学会了可复用能力。提升也可能只是因为上下文变长，或者刚好看到了相似答案。与此同时，技能库可能越来越庞杂，成本不断增加，以前能做好的任务反而退化。

## 方案怎么做

这份报告提出 SkillGate，把每次学习结果整理成有版本、能撤回的技能提交。候选技能必须在同一模型、工具和预算条件下，同时与“不使用历史经验”和“直接复用原始记录”进行比较，并且要在两组未参与学习的新任务上都取得正向收益，才能进入正式技能库。

业务试点的目标是在新任务上把成功率提高至少 10%，同时把模型输入量或单次任务成本降低至少 20%。所有结果都要记录技能来源、调用情况、历史任务退化和撤回过程，以便审计和复现；这些目标仍需在实际业务中验证。
