# EvolveNet：协作式 Harness 进化

## 一句话总结

EvolveNet 是一套面向数据不能集中共享的多智能体部署的协作式 harness 进化框架，其 2026 年 8 月 arXiv 论文通过广播共享起点、本地并行进化、GLOBAL/HOME 作用域合并和逐样本行为 gate，在五类 held-out 任务上将未进化 harness 的绝对得分提升 8.3–33.4 个百分点，使不同工作负载能够共享经验证的可执行程序适配而不汇总原始 workload。
