# Murakkab

## 一句话总结

Murakkab 是 MIT 与微软在 OSDI 2026 提出的云平台智能体工作流编排系统，通过声明式任务、离线画像及工作流与硬件联合优化，在论文的 24 小时视频问答与代码生成混合负载中将相对手工调优 LangGraph 基线的 GPU 数从 2,568 降至 912，为能够同时控制工作流、模型部署与资源调度的平台提供质量和时延目标下的资源节省方案。
