# 信号闸门路由器（SignalGate Router）

截至 2026-08-26，本报告参考 vLLM Semantic Router 论文（arXiv:2603.04444v4）设计了一套家庭智能体请求调度方案；论文实验显示，简单规则的判断时间中位数低于 0.1 毫秒，6 类任务共享轻量适配器后模型内存可由 3438 MB 降至 575 MB；本方案据此在请求进入大模型前先做分流，并在工具执行后检查结果，供产品与平台团队用四周试点验证能否在不降低任务完成率和安全审计覆盖的前提下减少云端调用、等待时间和推理成本。

## 场景问题

目前很多家庭智能体无论任务难易，都会先调用大模型并进行多轮推理。开灯、查询状态等简单指令也因此产生额外的推理用量和费用，用户可能等待十秒以上；系统还可能选错工具，门锁、支付等高风险操作也缺少执行前确认和执行后核验。这些问题会直接影响用户体验、留存和规模化经营。

## 方案描述

“信号闸门路由器”面向家庭智能体产品和平台团队。它先读取请求中的任务类型、风险、权限和设备状态，再决定直接返回缓存结果、调用固定工具、交给轻量模型，还是升级到主智能体；工具执行前后还会分别检查权限、风险和任务是否真正完成。四周验证目标是：简单或重复请求调用大模型的次数减少 40%–60%，低风险高频指令的典型响应时间降低 60%–80%，单次任务的推理用量成本降低 30%–50%，一次完成率提高 10–20 个百分点，并让所有高风险工具调用都经过执行前检查和执行后核验。
