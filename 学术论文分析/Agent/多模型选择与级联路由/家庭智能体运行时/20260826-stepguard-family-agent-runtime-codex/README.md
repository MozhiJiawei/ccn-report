# 分步守护系统（StepGuard）

截至 2026-08-26，本报告参考逐步骤优化计算机操作智能体的研究（arXiv:2604.27151）设计家庭智能体运行方案；该论文在公开测试中的最佳结果显示推理成本降低 74.6%、任务耗时降低 45.8%；本方案据此持续识别“任务卡住”“到达关键节点”和“出现高风险动作”三类事件，只在关键步骤升级到更强模型，并通过设备状态和操作回执确认任务是否完成，供团队用 8–12 周试点验证实际收益。

## 场景问题

家庭智能体往往把每一步操作都交给能力最强、成本最高的模型，即使任务非常简单也不例外。这会增加推理用量、等待时间和费用。此外，工具接口显示成功，并不代表设备已经达到用户想要的状态；高风险操作如果缺少用户确认和执行证据，也难以安全地规模化落地。

## 方案描述

“分步守护系统”面向家庭智能体平台和智能家居开发者。系统默认让固定工具或轻量模型完成普通步骤；只有检测到任务停滞、到达必须核验的关键节点，或即将执行高风险动作时，才调用更强模型。任务结束后，系统会核对设备状态、操作回执和用户目标，并把失败原因用于调整下一轮策略。试点目标是把强模型参与的步骤减少 40%–60%、单次任务成本降低 30%–50%、95% 请求的响应时间上限降低 30%–45%，并将任务成功率提高 8–15 个百分点。
