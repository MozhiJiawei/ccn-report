# AccentShield：防止匿名语音泄露口音

## 一句话总结

这项被 ICASSP 2026 收录的研究发现，常见的变声匿名技术虽然能隐藏说话人的音色，却仍可能泄露口音；研究覆盖 13 类英语口音，通过在变声时加入文字内容控制，使口音被识别的准确率平均下降 68%，整体匿名保护效果提升 11%，可用于降低客服录音和通话数据暴露用户地域及族群背景的风险。

## 场景问题

现有语音匿名技术主要改变音色，却常常保留发音习惯和口音，攻击者仍可能据此推断用户的地域或族群背景，给客服录音、语音数据共享和隐私合规带来风险。

## 方案描述

面向需要共享或分析匿名录音的数据团队，AccentShield 在变声过程中加入文字内容控制，使系统既改变说话人音色，也减少原始口音特征；研究覆盖 13 类英语口音，使口音识别准确率平均下降 68%，整体匿名保护效果提升 11%，可在保留语音可用性的同时降低敏感属性泄露。
