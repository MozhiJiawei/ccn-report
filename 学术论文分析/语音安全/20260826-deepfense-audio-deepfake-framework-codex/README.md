# DeepFense：统一评测语音造假检测模型

## 一句话总结

DeepFense 是一套被 Interspeech 2026 收录的开源评测框架，它把不同的语音造假检测模型放进同一套训练和测试流程，并比较了 400 余个模型、6 个训练数据集和 13 个测试数据集，结果表明预先训练好的语音特征提取模型是影响检测效果的关键，可帮助运营商和金融客服更快选型、复现实验并持续升级检测系统。

## 场景问题

不同语音造假检测方案通常使用各自的数据、训练方法和评价标准，企业很难公平比较模型，也难判断实验室里的高分能否延续到电话压缩、背景噪声和未知攻击等真实业务环境。

## 方案描述

面向语音安全研发和模型选型团队，DeepFense 把语音特征提取、真假判别、训练目标和信道增强拆成可替换模块，并在统一流程中比较 400 余个模型、6 个训练数据集和 13 个测试数据集；企业可用它建立覆盖跨数据集、跨信道和未知攻击的统一验收基线，减少重复开发，并以同一组指标持续追踪模型升级效果。
