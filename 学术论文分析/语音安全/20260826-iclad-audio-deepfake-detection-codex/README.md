# ICLAD：识别训练时没见过的语音造假

## 一句话总结

ICLAD 是一项被 ACL 2026 Findings 收录的研究，当系统遇到训练时没见过的语音造假方式时，它会比较新语音与已知真假样本的差异并动态选择判断方法，无需重新训练模型；研究在覆盖 126,348 段音频和 42 种语言的五个数据集上完成验证，并在 SpoofCeleb 数据集上将综合识别得分从 0.334 提高到 0.665，可用于增强真实通话中对新型合成语音的发现能力。

## 场景问题

语音造假技术更新很快，检测系统一旦遇到训练数据中没有的新模型、新语言或新说话人，识别效果往往明显下降，而频繁收集样本并重新训练又难以满足运营商和金融客服的上线速度要求。

## 方案描述

面向需要快速应对新型语音攻击的风控团队，ICLAD 会比较待测语音与少量已知真假样本的差异，再根据样本是否陌生动态选择判断方法，无需重新训练模型；该方案在覆盖 126,348 段音频和 42 种语言的五个数据集上完成验证，并在 SpoofCeleb 数据集上把综合识别得分从 0.334 提升至 0.665，可用于缩短新攻击出现后的检测适配周期。
