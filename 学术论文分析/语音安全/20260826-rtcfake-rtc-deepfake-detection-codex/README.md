# RTCFake：检测电话和会议中的合成语音

## 一句话总结

RTCFake 是一项被 ACL 2026 Findings 收录的研究，专门解决合成语音经过电话网络、视频会议压缩和环境噪声后难以识别的问题；研究使用约 600 小时数据，覆盖 10 类语音生成技术和 7 个真实通信平台，并通过检查语音内容与发音细节是否一致来发现造假，可用于提升运营商、云会议和客服热线对新型合成语音诈骗的拦截能力。

## 场景问题

合成语音经过电话窄带传输、会议软件压缩和环境噪声干扰后，原有的造假痕迹会被削弱，普通检测模型容易把诈骗语音判成真人，增加运营商、云会议和客服热线的欺诈漏报风险。

## 方案描述

面向通信平台的实时反诈系统，RTCFake 使用约 600 小时、覆盖 10 类语音生成技术和 7 个真实通信平台的数据训练检测器，通过检查语音内容与发音细节是否一致来识别造假；论文方案在未见噪声条件下将等错误率控制在 9.30%—13.40%，优于普通离线模型的 14.28%—18.65%，可作为通话接入网关的风险评分模块。
