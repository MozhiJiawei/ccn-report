Decision
值得受控复现 不是直接按发布数字规划容量，而是先验证迁移机制和收益口径。

迁移路径：把 Full Attention 拆成三层可控选择

Figure 4 · architecture
读图方法 从 dense attention 进入 post-training calibration，再落到 sparse prefill / sparse decode。
关键字 retrieval heads、16-d token indexer、dynamic top-p：分别对应 head / feature / token 压缩。
边界 不是裁掉 KV cache；保留长程召回头，用低维候选和动态预算减少全量 QK。
