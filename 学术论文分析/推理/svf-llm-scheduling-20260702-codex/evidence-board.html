2. 48 / 5 / 3 是理论竞争比口径

Table 1 · CR by alpha
48prior best被收紧的竞争比上界，不是 latency speedup。
5alpha = 1/2单请求峰值内存最多占半卡容量。
3alpha -> 0高并发、小请求占比时趋近 3。
口径锁定：worst-case competitive ratio bound，不能写成“48 到 5 倍实测提速”。
