# Intel-GPU-D-series

## 一句话总结

Intel GPU D-series是采用Xe3P架构、面向内存密集AI推理的350W风冷PCIe加速卡设计，Intel品牌卡配160GB LPDDR5X，ODM方案最高480GB，2026年10月12日公告披露客户送样已启动。
