# AMD-Helion

## 一句话总结

AMD Helion 是 AMD 于2026年10月12日发布的面向智能体工作负载的开放机架蓝图，通过最高32,768核的第六代EPYC纯CPU机架连接独立推理设施，或以EPYC与MI350P同平台集成执行和推理，供伙伴按企业与超大规模客户需求定制。
