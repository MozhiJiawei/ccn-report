# OCP2026-开放以太网

## 一句话总结

OCP于2026年10月展示的开放以太网方案通过Tahan的16加速器Scale-Up互联、FPF八平面Scale-Out及统一FBOSS运维扩展AI集群网络，102.4Tbps为交换平台规格，72加速器机架与ESUN数据平面仍是后续方向。
