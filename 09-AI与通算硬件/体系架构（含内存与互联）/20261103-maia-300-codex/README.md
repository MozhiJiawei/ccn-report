# Maia-300

## 一句话总结

微软于2026年10月12日披露的Maia 300是面向大语言模型推理的软硬件协同平台，通过SDLA、NUMA多芯粒和每加速器288GB HBM4及18TB/s带宽改善数据局部性，并以96加速器机架和最高12,288加速器superpod扩展推理规模。
