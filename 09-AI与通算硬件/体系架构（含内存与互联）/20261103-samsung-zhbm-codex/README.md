# zHBM

## 一句话总结

三星于2026年10月29日披露的zHBM是面向AI数据搬运的在研内存架构，通过将内存直接堆叠于处理器上、结合WoW、混合铜键合、细间距TSV与分布式I/O探索短宽互联，尚未公布量化实测与量产日期。
