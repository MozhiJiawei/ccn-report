# Beluga-CXL共享缓存

## 一句话总结

Beluga v2（2025年11月27日）以CXL共享池、GPU gather/scatter拷贝与共享元数据RPC减少长上下文KV搬运开销，在2台各8张H20、未量化Qwen32B、输入超过15K且全部KV预填双方2TB池的第二轮测试中相较MoonCake获得7.35倍QPS和13.00秒降至1.36秒的平均TTFT，但首轮P99退化且不能证明云栖原场实测。
