# BlueField-4-Scale-In

## 一句话总结

NVIDIA 于2026年8月24日提出的 BlueField-4 Scale-In 是面向 AI Factory 的接入、存储、安全与运维基础设施域，利用具备800 Gb/s 网络接口的 DPU、DOCA 服务和 Spectrum-X 网络把数据路径处理从主机 CPU 卸载，以支持多租户智能体工作负载。
