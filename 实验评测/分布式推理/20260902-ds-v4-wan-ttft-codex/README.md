# DS-V4 公网 PP 网络传输时延建模

截至 2026-09-02，本报告针对 Shard 在波兰、捷克、丹麦和爱沙尼亚六张 RTX 5090 上完成的 DS-V4 六 Stage 公网 PP 部署，基于五条 live `V4_TIMING` 应用层实测带宽（150.7、177.6、99.0、5.6、285.4 MB/s）、四档真实编码 frame 和三档实验 TTFT 建立纯传输时延模型，并以五跳均为 20 MB/s 的移动网络 best-case 对照揭示 2048 token 纯传输约 16.78 秒、相当于实验总 TTFT 的约 80%，用于判断移动网络替代固网时的长上下文体验风险。

## 归档内容

- `report.html`：可离线打开的 SingleFile 交互式报告。

## 口径与边界

- 固网条件来自仓库记录的五条 Stage 间应用层 uplink 实测值，不是运营商标称带宽。
- 移动网络采用五跳均为 20 MB/s 的场景假设，不代表中国 5G 网络的普遍实测水平。
- 纯传输时间不包含计算、RTT、排队、协议握手、重传和同步。
- 实验 TTFT 与模型的 prompt 长度和运行条件不完全一致，报告中的占比只作同量级对照，不作严格拆账。
