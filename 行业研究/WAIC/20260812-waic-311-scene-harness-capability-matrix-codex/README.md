## 交付内容

- `WAIC-311-场景-Harness-能力矩阵.html`：最终滚动式报告。

## 分析口径

- 场景：CSV 中的 `唯一二级类`，共 35 类。
- Harness：刚需 / 不刚需 / 未定。
- 能力：感知 / 认知 / 行动，强项可以同时出现，因此不是互斥构成。
- 分歧场景：同一二级场景至少 3 个样本，且存在两个以上 Harness 结论。
