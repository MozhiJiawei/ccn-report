# NetCanvas-网络拓扑

## 一句话总结

截至 2026 年 9 月，华为 GTS NetCanvas 将动态网络拓扑作为 Agent 的外部视觉工作记忆，在 CTBench 中把交互视觉拓扑的正确率提升到 54.5%，预加载物理拓扑达到 63.6%，并在双防火墙排障任务上报告约 90% 通过率。
