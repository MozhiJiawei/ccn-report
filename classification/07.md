# 07-AI安全、可信与治理

## 顶层责任

AI 风险、攻击防护、隐私、治理和合规

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| AI系统攻防 | Agent系统攻防、Prompt injection、jailbreak、工具/记忆投毒、供应链攻击、漏洞利用、红队和防护 |
| 模型安全与可控 | 对齐失效、幻觉风险、鲁棒性、可解释性、水印、拒答、模型行为控制 |
| 隐私、数据与知识产权 | 数据泄露、数据主权、隐私计算、训练数据版权、生成内容权利和知识产权 |
| 治理与合规 | AI 法规、监管、审计、责任边界、风险管理框架和企业治理 |

## 易混淆边界

主贡献是AI风险、防护、隐私或治理。通话场景中将检测、路由和业务动作组成产品方案的报告归通信网络，安全方法可作次要标签。正式标准进展归标准板块，企业合规实践归本板块。

- VoxGuard：检查匿名语音是否仍会泄露身份 → 07-AI安全、可信与治理/隐私、数据与知识产权：VoxGuard评估匿名语音身份与敏感属性泄露风险。
