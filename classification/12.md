# 12-基础竞争力（系统&软件领域的工程与技术）

## 顶层责任

可跨领域复用的性能、内存、成本和研发工程能力

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| OS与编程语言（含编译器） | 改变系统执行、语言、编译或运行时机制 |
| 分布式计算与并行技术 | 改变多执行单元的任务分解、通信、同步或协调机制 |
| 成本、能耗与资源效率 | 改变资源计量、容量配置、使用治理或成本/能源约束下的决策 |
| 软件工程与研发效率 | 改变软件开发、验证、构建、交付、诊断或维护过程 |

## 易混淆边界

可跨业务复用的系统与软件工程能力。专用于模型推理的优化优先归推理，训练专用系统归训练；跨训练与推理的通用通信机制可归分布式计算。
