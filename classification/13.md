# 13-产业新闻

## 顶层责任

无法归入上述技术板块但具有显著产业决策价值的事件
优先评分：比如：诺基亚出售自己的电信云、电信供应商跟AI公司合作

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| 企业经营与战略 | AI、云、芯片等企业的关键经营结果、战略转向和组织能力变化 |
| 投资与并购 | 重要融资、收购、出售、拆分和资本投入 |
| 产业合作与竞争 | 重大合作、生态竞争、市场进入、商业模式和竞争格局变化 |
| 市场供需与供应链 | 关键产能、供需、出口限制、供应链中断和价格结构变化 |
| 产业政策与监管 | 非 AI 安全治理类的产业政策、贸易政策、许可和市场监管 |

## 易混淆边界

仅承载无法归入技术板块且具有显著产业决策价值的事件。技术报告、综述和无法判定的材料不能兜底放入产业新闻；以经营、交易、供需或政策事件的主要决策影响归二级。
