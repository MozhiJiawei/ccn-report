# 08-云与AI基础设施

## 顶层责任

AI 云、数据中心、资源管理、虚拟化和异构调度

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| OS、虚拟化与隔离 | 操作系统、虚拟机、容器、沙箱、机密计算和租户隔离 |
| 应用与资源调度 | Kubernetes、Kueue、Slurm、Ray 等工作负载调度、弹性、队列和容量治理 |
| 异构资源管理与抽象 | GPU/NPU/DPU 资源池、DRA、设备插件、异构编排和算力抽象 |
| 智算中心与云平台 | AI Factory、数据中心、云平台、供电散热、AI 网络和存储平台 |

## 易混淆边界

承载云平台、集群及租户层面的资源管理。模型内部调度与并行部署归推理；新芯片、内存互联硬件归硬件；跨领域操作系统原理归基础竞争力。

## 已归档判例

- ASI-异构集群调度 → 08-云与AI基础设施/应用与资源调度：ASI通过碎片整理、预留和可回收借用分配共享GPU作业容量，主对象为工作负载及容量调度C2，而非硬件异构抽象或泛成本治理。
