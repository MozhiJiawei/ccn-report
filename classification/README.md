# CCN Report 分类总则

## 归档前加载顺序

1. 先阅读本总则，依据文章主问题和主要贡献选择候选一级板块。
2. 加载下表对应的板块细则；跨板块时同时加载双方细则，比较顶层责任与边界。
3. 阅读正式报告正文，不能只按标题、厂商、来源形式或少量关键词归类。确定唯一主归属后再创建目录。

## 层级与综述

一级目录统一使用`两位序号-分类名称`，按照下表固定为`01-`至`13-`；序号是目录名的一部分，二级目录不编号。一级直归README中的“一级分类”填写含序号的完整目录名。

保留13个一级、50个二级分类。使用既定名称，不自行新增分类或中间层。

- 普通专题：`一级分类/二级分类/YYYYMMDD-report-slug-creator/`。
- 无适配单一二级的综述／综合：`一级分类/YYYYMMDD-report-slug-creator/`。
- 有明确二级主题时必须进入二级；提到多个主题不自动构成一级直归。
- 一级直归README必须包含“文章类型：综述／综合”“一级分类：实际一级名称”“一级直归理由：具体说明”，说明一级承载理由及为何无单一二级适配。
- 不设置“其他”“综合”目录。内容未理解或证据不足时先核实，不能以一级直归或产业新闻兜底。
- 次要关联可写入README作为检索标签，不复制报告；重复出现的新主题应先提出分类修订，再调整规则。
