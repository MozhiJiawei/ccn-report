# 02-智能体平台、协议与执行系统

## 顶层责任

Agent 的架构、运行、记忆、协议、工具和观测

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| Agent架构与编排 | 单/多 Agent 架构、规划、任务分解、协作、工作流编排和运行时状态管理 |
| 记忆与上下文系统 | 长短期记忆、情景记忆、记忆检索、上下文工程、状态持久化和遗忘机制 |
| 协议与互操作 | MCP、A2A、Agent 通信、能力发现、身份协商和跨平台互操作机制 |
| 工具调用与执行系统 | Tool calling、浏览器/代码/终端执行、沙箱、权限、技能注册和执行可靠性 |
| 评测与可观测 | Agent 任务成功率、轨迹评测、工具调用评测、运行追踪、Agent benchmark 和可观测性 |

## 易混淆边界

Sub-Agent明确属于Agent架构与编排。按主要改变对象区分编排、记忆、协议、执行和评测；工具经验记忆图归记忆，工具执行器归执行。模型参数更新归模型训练，模型通用能力基准归模型评测。

## 已归档判例

- Anthropic Sub-Agent 官方材料分析 → 02-智能体平台、协议与执行系统/Agent架构与编排：Sub-Agent分工、并行、上下文隔离及主Agent综合，直接命中多Agent架构与编排；同名处理仅是路径实施事项。
- OpenAI Sub-Agent 官方材料分析 → 02-智能体平台、协议与执行系统/Agent架构与编排：Sub-Agent把探索验证分到独立上下文并由主Agent综合，直接命中任务分解协作编排；命名不产生分类歧义。
- ToolAtlas：把 Agent 记忆变成工具基础设施 → 02-智能体平台、协议与执行系统/记忆与上下文系统：ToolAtlas把工具用法、失败边界与组合经验组织成提供方三层记忆图，执行时检索并压成guidance；主改进对象是共享经验的组织与检索，不是工具执行器或可执行技能包。
- Graph Engineering 技术洞察 V3｜从问题到关系状态 → 02-智能体平台、协议与执行系统/记忆与上下文系统：正文明确图是共享事实账本而非流程图：实体消歧、关系及来源链、子图检索和跨会话长期状态属于记忆与上下文系统。
- WAIC Agent 行业技术需求分析 → 02-智能体平台、协议与执行系统/Agent架构与编排：全文以完成协议、状态权限、验证器与运行时差异组织33个行业交叉格；核心回答Agent架构如何适配行业，125个产品是约束证据，归架构与编排。
- 智能应用竞争力四元分类 → 02-智能体平台、协议与执行系统/评测与可观测：正文提出Agent客户任务的泛化、闭环成功率、端到端时延、单位成功任务成本及验收方法；本质为任务评估方法，A5明确包含Agent任务成功率与评测，跨应用案例是方法说明。原P4并非必要。
- Oracle Agent Memory：企业级长时记忆底座技术报告 → 02-智能体平台、协议与执行系统/记忆与上下文系统：核心对象为企业Agent的长期记忆基础设施。
- Rokid AIOS 与 Rokid/docs 公开能力深度洞察 → 02-智能体平台、协议与执行系统/协议与互操作：正文核心是Rokid公开平台的CloudApp请求/响应、身份认证、技能接入和设备动作协议；既有异构设备身份与跨服务协议，A3已有责任足够覆盖。
- SkillOpt Agent Skill Optimization → 02-智能体平台、协议与执行系统/工具调用与执行系统：SkillOpt优化Agent技能文档，交付对象为可复用技能。
- AgentSysBench：智能体工作负载与服务系统分析 → 02-智能体平台、协议与执行系统/评测与可观测：用统一观测框架刻画Agent全链路负载与瓶颈。
- TRACE：从执行轨迹定位上下文故障 → 02-智能体平台、协议与执行系统/评测与可观测：通过执行轨迹反向归因上下文故障并生成维修建议。
- HCRC 技术长报告：用 Heaviside 门控约束 LLM 认知熵 → 02-智能体平台、协议与执行系统/工具调用与执行系统：HCRC用外部predicate与测试约束执行状态提交，防止虚假完成。
- Managed Autonomy at Runtime｜Agent 运行时安全与治理技术洞察 → 02-智能体平台、协议与执行系统/工具调用与执行系统：EntropyRuntime实际决定动作执行权限、拒绝、降级与恢复，是Agent运行时权限和执行控制，A4比制度治理更直接。
- Avernet 技术深读报告 → 02-智能体平台、协议与执行系统/协议与互操作：正文明确BCS是主线，解决不同来源Agent的注册、发现、连接、消息路由与异构接入；BaaS执行与Engine适配服务于协作网络，主归A3。
- 智能体协议全景：从原生机制到智能体网关诉求 → 02-智能体平台、协议与执行系统/协议与互操作：比较Agent协议、通信和跨系统网关互操作需求。
