# 10-通信网络与产业实践

## 顶层责任

通信网络技术、AI 服务、产品商用及产业经营

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| 核心网与网络架构 | 交换网络、EPC/5GC/6GC、SBA、UPF/AMF/SMF/PCF/UDM/NRF、切片、QoS、MEC、承载协同和云原生网络架构 |
| 话音、消息与实时通信 | IMS、VoLTE、VoNR、OTT 话音创新、消息、实时音视频、号码和业务连续性 |
| 网络智能化与高稳运维 | 自治网络、NWDAF/MDAF 的运维应用、故障闭环、可观测、网络韧性、SLA 和高稳保障 |
| 体验经营 | VPN阻断、流量经营、低时延网络、算力入网 |
| 网络开放与API | NEF、CAMARA、Open Gateway、QoD、号码验证、SIM Swap 和网络能力商业开放 |
| 端云协同AI创新 | 基于网络的 |

## 易混淆边界

以通信网络、实时通信与网络业务实践为主体。基于检测论文形成IMS、SBC、WebRTC网关及通话业务闭环的PoC设计也属于本板块，但必须区分设计与已验证收益。正式协议发布归标准板块。

## 已归档判例

- DeepFense：统一评测语音造假检测模型 → 10-通信网络与产业实践/话音、消息与实时通信：正式HTML是DeepFense Shield通话安全方案，围绕信道感知、检测、隐私及业务决策形成运营闭环，归话音与实时通信；论文基准是设计依据，PoC收益未验证。
- ICLAD：识别训练时没见过的语音造假 → 10-通信网络与产业实践/话音、消息与实时通信：正式HTML是面向云核心网、IMS及呼叫中心的VoiceGuard方案，设计检测与匿名化双闭环、质量路由和业务动作，归话音与实时通信；这是PoC设计而非商用实绩。
- RTCFake：检测电话和会议中的合成语音 → 10-通信网络与产业实践/话音、消息与实时通信：正式HTML是RTCGuard-PCL通话检测网关方案，核心为SBC/WebRTC部署、流式检测和风险联动，归话音与实时通信；论文方法为依据，产品收益待PoC验证。
- WAIC 2026 具身智能：算力、数据与5G-A供数技术长报告 → 10-通信网络与产业实践/端云协同AI创新：正文围绕端—边—云分工、基站感知供数及MEC协作支持具身智能，主决策是网络介入AI供给的路径，N6端云协同AI创新足以承接；原举例未写完不妨碍标题及顶层责任。
