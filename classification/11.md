# 11-标准、协议与产业联盟

## 顶层责任

正式标准、协议版本、工作组和开放生态治理

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| 标准与协议进展 | 3GPP、IETF、ETSI、IEEE、GSMA、TM Forum、O-RAN、CXL、UALink 等规范、Release、Work Item、API Release 和正式提案 |
| 产业联盟与开放生态 | 联盟成立、成员变化、参考架构、认证、PlugFest、开源治理和生态阵营变化 |

## 易混淆边界

正式规范、版本、工作项、认证与生态治理归本板块；基于规范设计或优化的具体技术系统按其业务责任归类。合作新闻只有以联盟或开放生态治理为主时归本板块。

## 已归档判例

- DMSC 智能体网关｜最新 -07 架构、部署与标准化全景 → 11-标准、协议与产业联盟/标准与协议进展：固定IETF个人草案-07逐项拆解规范对象、部署及标准化缺口，属于标准与协议进展Z1；提案不必是已定稿标准。
