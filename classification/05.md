# 05-模型训练

## 顶层责任

预训练、后训练、强化学习、数据和训练效率

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| 预训练与训练数据 | 预训练目标、数据构建、清洗、合成、课程学习、数据污染和数据治理 |
| 微调、后训练与对齐 | SFT、DPO、偏好优化、持续训练、领域适配、对齐和后训练方法 |
| 强化学习与奖励学习 | RLHF、RLAIF、PPO、GRPO、奖励模型、过程奖励、Agent RL 和环境反馈学习 |
| 训练系统与训练效率 | 分布式训练、并行策略、检查点、容错、训练吞吐和训练成本优化 |

## 易混淆边界

主贡献是参数学习、训练目标、数据或训练效率。SFT与偏好优化归后训练，奖励和环境反馈归强化学习；冻结模型参数、演化外部记忆的机制归Agent记忆与上下文。

## 已归档判例

- Parametric Skills 技术报告 → 05-模型训练/微调、后训练与对齐：正文将文本技能编译为LoRA参数，并以训练形成可注入适配器。
- Skill Self-Play：让技能库驱动可验证自进化 → 05-模型训练/强化学习与奖励学习：Skill Self-Play以可验证任务和技能库共同训练proposer与solver。
- OpenForge RL 技术报告｜arXiv 2607.21557v2 → 05-模型训练/训练系统与训练效率：正文明确是Harness原生训练基础设施，涵盖远程rollout和轨迹重建。
- 从奖励到可复用经验｜SRRL 技术洞察报告 → 05-模型训练/强化学习与奖励学习：SRRL通过奖励、自审和选择性蒸馏把成功行为学习进策略。
- MemSFT 技术报告｜arXiv:2607.25614v1 → 05-模型训练/微调、后训练与对齐：MemSFT训练外部memory LM及router缓解领域SFT的对齐损失。
- UltraEP 实时 MoE 专家负载均衡 → 05-模型训练/训练系统与训练效率：主机制是MoE训练及prefill的实时专家负载均衡，2560 GPU生产训练为主要系统验证；T4训练并行与吞吐范围足够，serving是次要关联。
- Source Understanding Review → 05-模型训练/微调、后训练与对齐：正文研究Log-ICoT由完整CoT监督逐步内化隐藏状态的训练过程和可学性，属于T2训练迁移/蒸馏式后训练；不是部署时裁剪现成输出。
- E-GRM：基于模型内部不确定性的按需推理 → 05-模型训练/强化学习与奖励学习：正文生成式奖励建模结合短长样本SFT、GRPO偏好优化及判别质量评分；原T3明确包含奖励模型，按需推理是奖励模型效率设计，足以裁决。
- GeoPipe 跨数据中心训练 → 05-模型训练/训练系统与训练效率：GeoPipe面向跨数据中心LLM训练改进流水线并行。
- Explorative Modeling 来源理解归档 → 05-模型训练/预训练与训练数据：XM明确不是新网络而是生成模型训练目标，训练时best-of-K匹配真实样本，模型训练T1中的训练目标可承接；不因生成图像/视频而归应用或新增模型类。
