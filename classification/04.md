# 04-AI模型

## 顶层责任

模型本体、模型发布、模型架构，以及模型领域的基础理论与能力演进综述

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| 文本模型与模型架构 | 文本类模型LLM/LRM |
| 话音模型与模型架构 | 话音模型（ASR/S2TT/TTS/） |
| 多模态模型与模型架构 | 图片、视频等模态的理解、生成与编辑，Omni及世界模型；模型按模态归类，不按理解或生成任务拆分。 |

## 易混淆边界

模型按模态划分；多模态统一包含理解、生成、编辑、Omni和世界模型。训练方法归模型训练，Serving优化归AI推理与服务加速。AGI/ASI基础理论与能力演进综述可直接归本一级。

## 已归档判例

- Boogu-Image-0.1 来源理解归档 → 04-AI模型/多模态模型与模型架构：图像生成与编辑模型家族。按用户确认，多模态分类统一覆盖理解、生成与编辑，归入多模态模型与模型架构。
- From AGI to ASI | 洞察报告 → 04-AI模型：研究AGI/ASI基础理论、智能能力与发展路径，属于模型领域综述，无法由单一模态子类承载，直接归AI模型一级目录。
- Agent 需要世界模型来预演环境反馈 → 04-AI模型/多模态模型与模型架构：Excel在M3明确列入世界模型，语言形式不改变动作条件环境状态预测这一模型对象，直接归M3。
- Looped World Models 技术报告 → 04-AI模型/多模态模型与模型架构：共享循环Transformer块与latent refinement改变世界模型本体架构；M3明确覆盖世界模型，无须新增边界。
- Memory for Large Language Models：模型级记忆架构综述 → 04-AI模型/文本模型与模型架构：综述注意力、循环状态、可写参数等模型级记忆架构。
- HiLS-Attention：面向超长上下文的层次化稀疏注意力 → 04-AI模型/文本模型与模型架构：块级质量分数参与最终注意力并由语言模型损失反传，贡献是原生可训练注意力结构；模型本体架构M1优先，速度是结构效果。
- 2026年大模型架构演进主报告 → 04-AI模型/文本模型与模型架构：报告四条路线都围绕大语言模型计算结构、稀疏容量和token生成架构，M1可以收纳综合模型架构研究，无须因多条路线待定。
