# 09-AI与通算硬件

## 顶层责任

芯片、加速器、内存互联和计算体系架构

## 二级分类与边界

| 二级分类 | 范围与示例 |
| --- | --- |
| 芯片与加速器 | CPU、GPU、NPU、TPU、ASIC、DPU、制程、封装、产能和芯片路线图 |
| 体系架构（含内存与互联） | 服务器体系架构、HBM/DRAM、CXL、NVLink、UALink、Chiplet、存储层次和硬件协同 |

## 易混淆边界

以芯片、硬件结构、内存与互联实现为对象。复用既有编解码硬件做软件通信优化不构成新硬件架构；机房供电散热和云平台建设归基础设施。

## 已归档判例

- RED-PIM：PIM Transformer 推理数据移动优化 → 09-AI与通算硬件/体系架构（含内存与互联）：改变PIM attention跨bank数据移动及中间矩阵，属于存内计算算法与体系架构协同；H2直接承接。
