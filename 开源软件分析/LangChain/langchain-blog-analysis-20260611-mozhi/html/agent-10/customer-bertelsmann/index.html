一句话带走

Bertelsmann Content Search 用 LangGraph 做成生产级多 agent 搜索系统，把自然语言查询路由到领域 agent，再合成为统一答案。

关键机制

协调 agent 分析意图并并行调用出版、广播、新闻、Web intelligence 等专用 agent；各 agent 可接入向量库、API、图数据库和自定义工具，也能作为独立 API 嵌入部门系统。

阅读定位

这是一篇case study，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

分散内容库需要编排，而不是强行集中数据

文章的关键选择是保留各业务单元既有系统，让专用 agent 贴近数据源部署，再通过统一入口合成跨平台发现结果。

Coordinator 与并行 domain agents 形成内容发现网络

查询先由 coordinator 判断语义和领域相关性，再触发出版、广播、新闻、外部趋势等 agent 并行搜索，最终汇总成可行动洞察。

生产价值体现在秒级发现与部门内复用

原来需要跨多个系统手工查找的内容发现可缩短到秒级；同一个专用 agent 还能通过模块化 API 嵌进部门自己的 CMS 或档案界面。
