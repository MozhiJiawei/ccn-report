一句话带走

Open Deep Research 是基于 LangGraph 的可配置开源研究 agent，允许用户自带模型、搜索工具和 MCP server，并生成研究报告。

关键机制

系统分 Scope、Research、Write 三阶段：先澄清并压缩成 research brief，再由 supervisor 派发并迭代子研究 agent，最后用汇总 findings 一次性写报告。

阅读定位

这是一篇technical longform / open source，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

研究策略先由 brief 锁定目标

用户对话会被转成聚焦的 research brief，作为 supervisor 判断研究是否足够、最终报告是否满足请求的北极星。

多 agent 只用于容易并行的研究部分

文章明确反思早期并行写作会让报告割裂，因此将子 agent 限定在独立子主题研究，最终写作由一个 LLM 调用完成。

context engineering 控制 token 膨胀

聊天历史压缩成 brief，子 agent 清理原始搜索反馈后再交给 supervisor，避免长网页、失败工具调用和无关内容拖垮上下文。
