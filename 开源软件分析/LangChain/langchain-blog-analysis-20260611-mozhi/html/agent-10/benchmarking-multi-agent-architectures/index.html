关键机制

实验给 retail 场景逐步加入 6 个无关 domain，每个含 19 个工具和 wiki；改进 supervisor 的关键是移除 handoff message、直接 forward sub-agent 输出并测试 handoff tool naming。

阅读定位

这是一篇technical longform / benchmark，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

测试重点是多余上下文的干扰

新增的 home improvement、tech support、pharmacy、automotive、restaurant、Spotify 等 domain 并不帮助 retail 场景，只用于测试架构过滤噪声的能力。

swarm 与 supervisor 的差异来自翻译层

swarm 中 active sub-agent 可直接回复用户；supervisor 需要转述 sub-agent 输出，因此更容易出现 telephone 问题并消耗更多 token。

supervisor 可泛化，但朴素实现不够

减少 handoff 噪声、允许 forward_message 直接传回子 agent 内容、调整 tool name 后，generic supervisor 更接近可用。
