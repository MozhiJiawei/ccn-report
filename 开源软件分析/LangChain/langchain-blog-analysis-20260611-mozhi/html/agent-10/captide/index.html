一句话带走

Captide 在 LangGraph Platform 上运行金融领域 agent，基于 14,000 多家上市公司的结构化披露库，把原本耗时数小时或数天的研究压缩到秒级探索。

关键机制

LangGraph Platform 支撑成千上万个表格单元并发调用、会话状态保存与生成式 UI；LangSmith 追踪成本、准确率、延迟并用循环 eval 捕捉常见和边界请求。

阅读定位

这是一篇case study，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

金融 agent 的负载既有长推理也有大并发

从连续问答到 spreadsheet-like 批量填充，Captide 需要同时处理上下文一致性和瞬时高并发。

产品专家能直接参与 agent 行为迭代

LangGraph Studio 的 low-code 界面让金融 domain experts 把客户反馈和行业知识带入 prompt 与 agent 设计。

生成式 UI 让研究路径可追溯

agent 会把交互式 React 组件和步骤更新流式推到界面，让用户看到检查了哪些来源、发现了什么以及为何得出结论。
