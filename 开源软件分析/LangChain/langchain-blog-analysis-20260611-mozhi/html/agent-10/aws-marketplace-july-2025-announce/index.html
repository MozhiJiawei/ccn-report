一句话带走

LangSmith 和 LangGraph Platform 进入 AWS Marketplace 的 AI Agents and Tools 类别，支持用 AWS 账号发现、购买和部署。

关键机制

两者以 self-hosted Helm chart 形式运行在客户 AWS VPC 和 Amazon EKS 内，结合 AWS 集中采购、许可管理、隐私控制与 LangChain 的调试、评估、部署能力。

阅读定位

这是一篇release，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

Marketplace 把 agent 平台纳入企业采购路径

文章的实质不是功能大改，而是让团队用 AWS 现有账号完成购买、许可、付款和访问控制。

LangSmith 覆盖 prompt、eval 和 observability

Prompt Hub、Prompt Playground、实验、annotation queue、dataset、trace 和 alert 共同支撑调试、测试和生产监控。

LangGraph Platform 面向长运行 agent 部署

1-click GitHub 部署、checkpoint、memory、Studio、agent registry 和 assistants 让团队在 AWS 内运行 stateful agent。
