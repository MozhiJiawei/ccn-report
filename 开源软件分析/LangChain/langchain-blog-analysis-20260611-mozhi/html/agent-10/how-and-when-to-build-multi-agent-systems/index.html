阅读定位

这是一篇technical opinion，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

读取型工作比写入型工作更适合并行

搜索和研究可以分方向探索再汇总；多个 agent 同时写代码或写内容，会产生隐含决策冲突和难以合并的结果。

每个 sub-agent 都需要清晰边界

目标、输出格式、工具、资料来源和工作范围如果描述不清，sub-agent 会重复搜索、遗漏信息或误解目标。

生产问题不止架构图

长运行 agent 还需要可恢复执行、错误处理、trace、LLM-as-judge、人类评估和小规模数据集。
