阅读定位

这是一篇technical explainer，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

长流程首先需要能安全暂停和恢复

agent 可能等待工具、API 或人工反馈，重启会丢进度且代价高；持久执行和 checkpoint 让运行跨过崩溃、暂停和超时。

状态不只是消息缓冲区

中间结果、工具输出、嵌入文档、多轮上下文都属于 agent state，需要可保存、可恢复、可干预的结构。

流式输出同时服务用户体验和调试

token-level streaming、custom data streaming 与 generative UI 让中间思考、工具调用和结构化输出可见，并可追溯到具体 graph 节点。
