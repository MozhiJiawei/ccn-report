文章把能处理长周期研究、编码等复杂工作的形态称为 deep agents，其核心算法仍是 LLM tool loop。

deep agents 在 tool loop 外叠加详细系统提示、规划工具、子 agent 和文件系统，让目标、分工和长期上下文更稳定。

深度来自外围结构，而不是换掉核心算法

文章把 Deep Research、Manus、Claude Code 的共同点抽象成四个结构：系统提示、规划、子 agent 和文件系统。

规划和文件系统让长流程不只靠聊天上下文

Todo 类规划工具把目标留在上下文里，文件系统承担笔记、共享工作区和长期记忆，避免长流程只堆在消息历史中。

deepagents 包把这套结构开放给垂直场景

开源包内置通用系统提示、no-op Todo 规划工具、子 agent 能力和虚拟文件系统，允许用户换 prompt、工具和子 agent。
