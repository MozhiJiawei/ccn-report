一句话带走

Align Evals 是 LangSmith 的评估器校准功能，用人工标注样本对照 LLM-as-a-judge 分数，显示 alignment score 和未对齐案例。

关键机制

用户选择评估标准、挑选代表性样本、给出人工期望分数，再在 playground 式界面中迭代 evaluator prompt，并与保存的 baseline 比较。

阅读定位

这是一篇release，重点看它如何把具体场景、产品能力或架构取舍连成一个可执行判断。

评估器本身也需要可迭代

文章把问题从“如何评应用”推进到“如何评评估器”：如果 judge 与人工偏好不一致，后续实验结论就会失真。

人工 golden set 是校准的锚点

流程要求先定义 criteria，再挑选好坏样本并人工打分；这些样本构成基准，用来衡量 evaluator prompt 的版本变化。

界面把错配案例直接暴露出来

侧栏对比人工分与 LLM 分，支持按不一致排序；baseline alignment score 让团队知道 prompt 修改到底改善还是恶化。
