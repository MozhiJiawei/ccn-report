Open SWE 把编码 agent 放进真实工程流

它不是只在编辑器里给建议，而是连接仓库、跟踪 issue、输出执行计划、运行测试并提交 PR。文章重点强调异步、云端、可中断和 GitHub 原生协作这些交互形态。

多 agent 流程减少直接写代码的脆弱性

Manager 处理入口，Planner 先研究代码库并形成计划，Programmer 在沙箱中执行，Reviewer 负责检查质量与完整性；计划审阅和运行中反馈让人可以在关键节点介入。

LangGraph 和 LangSmith承担长流程运行与改进

LangGraph 编排四类 agent 状态与边界，LangGraph Platform 提供持久化、自动扩缩和长时间运行能力，LangSmith 用于调试和评估 context engineering。
