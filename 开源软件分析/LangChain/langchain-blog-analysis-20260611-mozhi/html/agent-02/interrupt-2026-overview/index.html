发布清单覆盖了 agent 平台的四个层面。

如果只看产品名会显得分散；按层面重排后，文章主线更清楚：观测与改进、运行基础设施、治理与协作、agent 能力与研究。

LangSmith Engine

从生产 traces 中聚类问题，生成修复 PR、在线 evaluator 与离线 eval 样本。

SmithDB

面向 agent observability 的 Rust 数据层，基于 Apache DataFusion、Vortex、对象存储和 Postgres metastore；原文称核心 LangSmith 体验最高快 15 倍。

Managed Deep Agents

API-first 托管运行时，支持 durable threads、streaming runs、checkpointing、human-in-the-loop、context/files 与 sandbox-backed execution。

LangSmith Sandboxes GA

为 agent 提供隔离代码执行环境，带 filesystem、shell、package manager、persistent state 和网络边界。

Context Hub

集中管理 agent 行为上下文，包括 AGENTS.md、skills、policies、examples，并支持 versioning、tags、comments。

LangSmith LLM Gateway

运行时治理层，提供 spend caps、PII/secrets redaction、policy events、trace continuity 与 audit logging。

LangSmith Fleet updates

Fleet 获得 sandbox access、5 个 prebuilt agents，并在 Developer 与 Plus plans 中包含由 Fireworks 支持的免费模型用量。

Deep Agents 0.6 + LangChain Labs

Deep Agents 0.6 增加 code interpreter、typed streaming、DeltaChannel；LangChain Labs 聚焦用 agent traces 推动 continual learning。
