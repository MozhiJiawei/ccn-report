LangChain Skills

Why：通用编码 agent 在 LangChain 生态里会缺少领域操作知识。What：LangChain 发布 11 个按需加载的 skills，把 LangChain、LangGraph、Deep Agents 的构建经验打包给 coding agent。How：通过 markdown、脚本和资源做渐进披露，并用 LangSmith evals 对比通过率，从 25% 提升到 95%。

Skills 把生态知识装成按需加载的能力包

文章把 skills 定义为 curated instructions、scripts 和 resources，用来提升 coding agent 在特定领域的表现。重点不是再加一个工具列表，而是让 agent 在相关场景里动态读取所需知识。

这一点回应了原文提到的历史问题：给 agent 过多工具会让性能下降。Skills 用 progressive disclosure 控制上下文暴露，让能力更像可检索的专门经验，而不是一次性塞满提示词。

11 个 skills 覆盖三条开源构建路径

LangChain

围绕 create_agent()、middleware 和 tool patterns，补齐经典 tool-calling agent loop 的基础用法。

LangGraph

围绕 primitives 展开，并覆盖 Human In the Loop、durable execution 等 LangGraph 原生能力。

Deep Agents

面向开源 Deep Agents package，强调 prebuilt middleware 和 FileSystem 的使用。

效果主张落在 25% 到 95% 的通过率

原文的核心论据是对照评估：Claude Code without Skills 在 Sonnet 4.6 上通过率为 25%，with Skills 为 95%。通过率由 LangSmith evaluations 计算，测试 benchmark 计划开源。

对比对象

同一类 basic LangChain、LangGraph、Deep Agent 用例，对比 Claude Code 是否获得 skills。

评估边界

文章没有把结果外推到所有编码场景；数字服务于“领域 skills 能显著改善生态内构建体验”这一发布主张。

安装路径把 skills 分发给项目、用户或指定 agent

发布页把使用门槛压到 npx skills：同一个仓库可以安装到当前项目、全局环境，或绑定到 Claude Code 这类指定 agent。

Localnpx skills add langchain-ai/langchain-skills --skill '*' --yes
Globalnpx skills add langchain-ai/langchain-skills --skill '*' --yes --global
Agentnpx skills add langchain-ai/langchain-skills --agent claude-code --skill '*' --yes --global

结尾还把这次发布接到持续更新计划：随着 Open Source 和 LangSmith 能力增加，skills 内容会继续扩展；同日也发布了 LangSmith skills。
