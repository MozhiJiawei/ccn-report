Why创建专门 agent 之前，用户常常只想先用已有工具完成一个临时任务。
WhatAgent Builder 新增常驻 Chat、conversation-to-agent、文件上传和统一 tool registry，把即兴工作和可复用 agent 创建接在一起。
HowChat 可调用 workspace 中 Slack、Gmail、Linear、Pylon 或 remote MCP server 等工具，任务过程中请求审批；有效对话可一键变成手动、定时或事件触发的 agent。

Central Chat 把工具使用提前到创建 agent 之前

用户可以直接问 open Linear tickets、summarize Slack support 或处理邮件，不需要先配置专门 agent。多个 chat thread 可并行运行，用户随时回来审批动作或查看进度。

有效对话可以直接沉淀成可复用 agent

文章强调 setup 就是 conversation：用户在任务中给反馈，得到满意输出后选择 Turn this conversation into a reusable agent，即可获得可手动触发、定时触发或响应 Slack/email 等事件的 agent。

File uploads 扩展了 agent 可见输入

此前 Agent Builder 主要依赖连接工具和 chat 文本。现在 CSV、截图、照片、style guide 或已有 prompt 都可直接上传，支持数据分析、图片处理和 reference material 注入。

Tool registry 给 workspace 管理员一个控制面

workspace settings 中可查看已连接工具、处理重新认证、添加 remote MCP servers。新工具连接后对所有 agents 可用，但只有管理员能添加，保留治理边界。
