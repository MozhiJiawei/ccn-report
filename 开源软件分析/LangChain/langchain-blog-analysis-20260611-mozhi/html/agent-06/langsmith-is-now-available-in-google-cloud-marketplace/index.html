核心判断LangSmith is Now Available in Google Cloud Marketplace

release / marketplace · February 9, 2026 · 4 min

Why企业在 Google Cloud 上构建 AI 应用时，希望采购、计费、合规部署和既有数据基础设施能保持在同一云环境。
WhatLangSmith 已上线 Google Cloud Marketplace，覆盖 observability、evaluation、deployment、Agent Builder，并延续 LangChain 与 Google Cloud 在 Gemini、A2A Protocol、MCP Toolbox for Databases 等方向的合作。
How客户可通过 marketplace 采购，用现有 Google Cloud invoice 和 committed spend，并在 SaaS、hybrid 或 GKE self-hosted 配置中部署 LangSmith。

Marketplace 发布服务于企业采购路径

文章强调 consolidated billing、committed spend drawdown 和 simplified procurement。对于已有 Google Cloud approved vendor 流程的企业，这降低了引入 LangSmith 的行政摩擦。

LangSmith 的价值被概括为四类能力

Observability 提供 tracing、monitoring、alerts 和趋势；Evaluation 支持 experiments、human feedback 和 reusable datasets；Deployment 管理 stateful long-running agents；Agent Builder 提供无代码 agent 自动化。

Google Cloud 集成覆盖模型、数据、计算和工具

文章列出 Gemini/Vertex AI Model Garden、AlloyDB、BigTable、BigQuery、Spanner、Firestore、Memorystore、GKE、Google Finance、Google Drive、Google Trends 等生态触点。

部署形态覆盖 SaaS 到自托管

LangSmith 可用 fully-managed SaaS、数据留在 VPC 的 hybrid deployment，或通过 Helm charts 和 Terraform modules 在 GKE 上 fully self-hosted，以匹配安全与合规需求。
