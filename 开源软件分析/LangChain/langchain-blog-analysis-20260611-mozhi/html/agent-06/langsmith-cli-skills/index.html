release / 薄观点文 · March 4, 2026 · 2 min

WhyLangSmith 的调试、数据集和评估流程正在进入 terminal-first 的 agent 开发循环。
WhatLangChain 发布 LangSmith CLI 与 3 个 LangSmith skills，让 Claude Code 在基础 LangSmith 任务上的通过率从 17% 升到 92%。
HowCLI 负责抓 traces、整理 datasets、运行 experiments；skills 用渐进披露提供 trace、dataset、evaluator 三类操作指南。

CLI 把 LangSmith 变成 agent 可操作的终端界面

文章把 CLI 定位为 agent-native 的基础层：coding agent 和开发者都能通过终端获取 traces、整理 datasets、运行 experiments。LangChain 认为这会支撑未来由 agent 驱动的 agent improvement loop。

Skills 承接领域知识，而不是把全部工具塞进上下文

LangSmith skills 是 markdown、脚本和资源组成的可移植包，只在任务相关时加载。文章特别强调，过多工具会让 agent 表现下降，渐进披露是提升能力和控制上下文的关键。

Trace、dataset、evaluator 串成改进闭环

三个 skills 分别对应 LangSmith AI engineering 的三块核心工作：加 tracing 并查询 traces、构建 examples 数据集、在数据集上评估 agent。文章最后把它们串成从 trace 到 debug、dataset、evaluator、architecture iteration 的循环。
