How Kensho built a multi-agent framework with LangGraph to solve trusted financial data retrieval

Why

金融数据分散在多个系统中，专业用户花大量时间查找、验证和整合信息；AI agent 若没有可信数据层，答案很难被信任。

What

Kensho 用 LangGraph 构建 Grounding multi-agent framework，为 S&P Global 数据提供统一 agentic access layer，并通过 Data Retrieval Agents 连接不同数据源。

How

系统以 centralized entry point 接收查询，router 聚合多个单职责 DRA 的结果，使用 custom data retrieval protocol 保持来源、结构和可验证性。

一句话带走

Kensho 的案例不是“让 agent 搜得更广”，而是让金融数据检索更可信。Grounding 用 LangGraph 组织多 agent 框架，每个 Data Retrieval Agent 负责一个数据垂直，router 再把分散来源聚合成可验证答案。

文章真正强调的三件事

问题来自结构化金融数据的碎片化

S&P Global 的数据高度结构化、细粒度且跨业务单元，普通 web search 式检索不够。

Grounding 是统一入口

框架为多个 AI agents 提供集中数据访问层，确保 insight 来自 verified datasets。

DRA 降低查询噪音

每个 Data Retrieval Agent 负责单一数据方向，router 解决跨来源聚合和 map-reduce。

支撑观点的机制

案例目标是可信检索而不是泛化聊天

金融专业人员需要的是可验证的指标、市场研究和文档信息。Kensho 把 agentic retrieval 建在 S&P Global 数据资产之上。

LangGraph 用于组织多 agent 控制流

Grounding 使用 LangGraph 工具，把 router、retrieval agents 和 aggregation layer 组织成一条可扩展框架。

协议层让不同数据源保持一致

custom data retrieval protocol 让每个 DRA 能以统一方式返回结构化结果，帮助上层 agent 处理来源和答案整合。
