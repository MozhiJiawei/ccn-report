Interrupt 2026 把 agent 议题推进到企业级规模

这篇预告不是单纯宣布会议日程，而是在给 LangChain 社区换一个问题：从“agent 能不能进生产”转向“企业如何把 agent 平台、评估、团队和基础设施一起放大”。

Why

去年 Interrupt 的生产化答案已经是 yes；今年真正悬而未决的是，当 agent 不再是概念验证，企业级系统要怎样运行。

What

Interrupt 2026 定在 5 月 13-14 日旧金山 The Midway，主题聚焦 agents at enterprise scale，并用 keynotes、fireside chats 和生产案例展开。

How

文章把答案落到三类证据：企业平台与数据层讨论、Lyft/LinkedIn 等生产实践、以及围绕 LangSmith、LangGraph、Deep Agents 的 hands-on 环节。

今年的问题从可行性变成规模化运行

800

上一篇章已经证明生产化热度

原文回顾 2025 年首届 Interrupt：800 人到场，Cisco、Uber、J.P. Morgan、Replit、LinkedIn、BlackRock 等团队分享了 agent 进入生产的真实经验。

Then

“Can agents work in production?”

去年围绕生产可行性展开，并伴随 LangSmith Deployment、重新设计的 LangSmith Studio 和 observability 工具发布。

Now

“How do you make them work at enterprise scale?”

今年关注企业如何建设 agent platforms、在高风险场景评估性能、围绕 agent engineering 组织团队，以及生态基础设施如何演进。

舞台内容用“生产中的团队”支撑规模化主题

企业级视角来自 keynotes 与 fireside chats

Harrison Chase 会谈过去一年与数千个 shipping agents 团队合作得到的经验、产品方向和行业预测；Andrew Ng 会分享 agents 的下一步；MongoDB CEO CJ Desai 会讨论 agents 从实验走向生产系统时的数据层。

Lyft 把评估做进具体业务边界

Lyft 的 Safety and Customer Care 团队会介绍如何围绕产品政策、用户流程和边界案例用 LangSmith 构建 evals，并把 failed traces、运营团队和工程反馈闭环连起来。

LinkedIn 用 agent 改造招聘流程

LinkedIn 工程团队用 LangSmith 和 LangGraph 构建 AI recruiting agent，原文给出的结果信号是团队 hiring 速度提升 10x。

会议形式把观点、产品和实操连成一条学习链路

Keynotes

LangChain 的产品方向、行业预测和 agent 工程经验先给出判断框架。

Production stories

Toyota、LATAM Airlines、Honeywell、Coinbase、Chime、Rippling、monday.com、Clay 等案例提供真实规模信号。

Demo stations

LangSmith 平台最新能力集中展示，参会者可以直接试用并与工程团队交流。

Workshops and AMAs

主题覆盖 building Deep Agents、LangSmith Align Evals、Insights Agent，以及面向产品负责人和演讲者的问答。
