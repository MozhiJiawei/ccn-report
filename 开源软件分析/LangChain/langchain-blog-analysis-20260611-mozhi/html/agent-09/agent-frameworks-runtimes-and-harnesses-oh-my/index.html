路径落在具体机制上

用抽象能力、生产运行能力、预置工作支架来区分三者，同时承认这些边界在早期领域仍然有重叠。

一套词汇让三个项目不再互相遮蔽

LangChain、LangGraph、DeepAgents 不是同一种抽象的三个名字，而是在开发速度、生产运行和默认工作支架上分别承担不同角色。

runtime 的标志是生产执行能力

LangGraph 被放在 runtime 层，因为它关心状态、持久化、人机协作和流式运行，而不是只封装一次模型调用。

harness 的标志是带有主张的默认工作方式

DeepAgents 不只是库函数集合；它把 planning、文件上下文、子 agent 和提示词实践预组装成一个起点。
