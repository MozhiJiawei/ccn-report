身份回答是谁，授权回答能做什么

文章首先拆开 authentication 和 authorization：前者确认主体，后者限制主体可执行的资源和动作。

agent 引入了代表执行的第二层主体

当 agent 替用户调用邮件、日历、数据库或内部工具时，系统要区分用户权限、agent 权限和工具自己的访问策略。

安全设计要让每次工具调用可约束、可解释

短期 credentials、scopes、consent 和审计日志让 agent 能行动，同时让越权、长期凭据泄露和模糊责任边界更少发生。
