路径落在具体机制上

LangGraph 编排多步骤诊断和工具调用，LangSmith 提供 traces、评测和调试视图，帮助团队把复杂分析流程产品化。

客户场景的难点是把调查过程系统化

Monte Carlo 的问题不是生成一句答案，而是让 agent 能沿着数据质量、告警、依赖和上下文逐步排查。

LangGraph 把诊断链路变成可控执行图

多步骤分析可以拆成状态、分支、工具调用和人工介入点，避免复杂流程只存在于提示词里。

LangSmith 让每次调查都可回看、可评测

traces 和评测让团队看清 agent 在哪里选错工具、漏掉信号或需要补充上下文。
