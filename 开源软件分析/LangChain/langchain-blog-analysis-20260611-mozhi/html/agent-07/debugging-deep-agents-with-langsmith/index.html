Debugging Deep Agents with LangSmith

Why：deep agents 会运行数十到数百步、跨多轮会话和超长 prompt，人工扫 trace 很难定位哪一步让行为偏离。 What：文章发布两条调试路径：LangSmith 内的 Polly 用自然语言分析 traces/threads，langsmith-fetch CLI 把 trace 调试带进本地编码 agent 工作流。 How：LangSmith 先记录 runs、traces、threads，再让 Polly 或 CLI 读取完整轨迹，回答效率、错误、prompt 修改和数据集构建问题。

Why

deep agents 会运行数十到数百步、跨多轮会话和超长 prompt，人工扫 trace 很难定位哪一步让行为偏离。

What

文章发布两条调试路径：LangSmith 内的 Polly 用自然语言分析 traces/threads，langsmith-fetch CLI 把 trace 调试带进本地编码 agent 工作流。

How

LangSmith 先记录 runs、traces、threads，再让 Polly 或 CLI 读取完整轨迹，回答效率、错误、prompt 修改和数据集构建问题。

deep agent 的失败分布在长轨迹里

prompt 很长、运行很久、用户多轮交互，错误可能来自早期上下文、工具选择或后续推理。

deep agent 的失败分布在长轨迹里

prompt 很长、运行很久、用户多轮交互，错误可能来自早期上下文、工具选择或后续推理。

Polly 把 trace 阅读变成对话式分析

在 Trace 或 Thread view 中提问，Polly 可以解释发生了什么、哪里低效、prompt 应如何修改。

langsmith-fetch 连接 UI 外的工作流

CLI 可按 ID 或时间拉取 traces/threads，并输出面板、pretty JSON 或 compact JSON 给本地工具使用。

这篇文章的论证链路

观察记录真实输入、输出、工具调用和上下文。
归纳把单次行为聚合成模式、失败类型或业务信号。
评价用 traces、datasets 或在线评分验证改动。
改进调整 prompt、工具、模型、memory 或 runtime。
