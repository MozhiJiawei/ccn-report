Introducing Polly: Your AI Agent Engineer

Why：当 agent 的 prompt、trace 和 conversation 都变长，单靠人工检查难以快速解释失败或找到有效 prompt 改法。 What：Polly 是嵌入 LangSmith 的 AI agent engineer beta，面向 trace 调试、thread 分析和 prompt engineering。 How：Polly 基于 LangSmith 捕获的 runs、traces、threads 工作，用户用自然语言询问执行过程、行为变化和期望改进，Polly 给出分析并可更新 prompt。

Why

当 agent 的 prompt、trace 和 conversation 都变长，单靠人工检查难以快速解释失败或找到有效 prompt 改法。

What

Polly 是嵌入 LangSmith 的 AI agent engineer beta，面向 trace 调试、thread 分析和 prompt engineering。

How

Polly 基于 LangSmith 捕获的 runs、traces、threads 工作，用户用自然语言询问执行过程、行为变化和期望改进，Polly 给出分析并可更新 prompt。

Polly 解决的是 agent 工程里的长上下文排障

它适合分析数百步 trace、跨小时或天的 thread，以及隐藏在 prompt 细节里的行为偏差。

三个入口覆盖从理解到修改

Trace view 解释单次执行，Thread view 追踪多轮上下文，prompt engineering 帮用户表达新行为并修改指令。

它依赖 LangSmith tracing 而不是凭空诊断

runs、traces、threads 提供完整行为材料，让 Polly 能把建议连接到实际执行证据。

这篇文章的论证链路

观察记录真实输入、输出、工具调用和上下文。
归纳把单次行为聚合成模式、失败类型或业务信号。
评价用 traces、datasets 或在线评分验证改动。
改进调整 prompt、工具、模型、memory 或 runtime。
