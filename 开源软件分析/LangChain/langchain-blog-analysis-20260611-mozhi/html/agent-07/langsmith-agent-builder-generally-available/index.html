Why

非开发同事也需要把日常研究、跟进、更新和跨工具操作自动化，但传统 workflow builder 约束先画清每一步。

What

LangSmith Agent Builder GA，把自然语言目标转成可部署 agent，自动生成指令、选择工具，并在需要时使用 subagents。

How

用户用反馈迭代 agent，借 memory 学习偏好，通过 MCP 接工具、共享克隆、选择模型，并可嵌入产品或 API 调用。
