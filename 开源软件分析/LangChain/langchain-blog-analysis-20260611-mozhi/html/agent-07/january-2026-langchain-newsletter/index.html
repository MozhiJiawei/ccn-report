Why

一月更新回答的是同一个运营问题：agent 不只要更容易搭出来，还要能被观察、评估和持续改进。

What

本期把 LangSmith Agent Builder GA、实验对比、自托管 Insights Agent、LangChain JS 与 deepagents 更新放在同一条主线上。

How

LangChain 用产品发布、开源改进、课程、支持门户和全球活动，把 agent 构建从一次性上线推进到持续运营。

一月主线从构建转向运行期改进

Agent Builder GA 降低构建门槛，observability 与 evaluation 内容则强调上线后的调试、评估和洞察。

一月主线从构建转向运行期改进

side-by-side LLM experiment comparisons、self-hosted Insights Agent 与支持门户，都服务于团队理解行为和协作排障。

生态信号来自课程、活动和客户故事

Academy、meetups、webinars 与客户案例把实践经验扩散到更广的 builder 社群。
