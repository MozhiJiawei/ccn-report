Agent Engineering: A New Discipline

Why：agent 从“本机可用”到“生产可靠”的距离很大，因为用户输入无限、模型行为开放，传统软件流程不足以稳定这种系统。 What：文章把 agent engineering 定义为把非确定性 LLM 系统迭代成可靠生产体验的新实践，循环是 build、test、ship、observe、refine、repeat。 How：这门实践结合 product thinking、engineering 和 data science：定义工作与 eval，建设工具、UI 和 runtime，再用生产数据分析与监控持续改进。

Why

agent 从“本机可用”到“生产可靠”的距离很大，因为用户输入无限、模型行为开放，传统软件流程不足以稳定这种系统。

What

文章把 agent engineering 定义为把非确定性 LLM 系统迭代成可靠生产体验的新实践，循环是 build、test、ship、observe、refine、repeat。

How

这门实践结合 product thinking、engineering 和 data science：定义工作与 eval，建设工具、UI 和 runtime，再用生产数据分析与监控持续改进。

上线不是终点，而是学习入口

agent 的真实失败和用户用法需要在生产中观察，越快完成循环，可靠性越容易提升。

上线不是终点，而是学习入口

agent 的真实失败和用户用法需要在生产中观察，越快完成循环，可靠性越容易提升。

三类技能共同承担 agent 可靠性

产品负责范围和 prompt，工程负责工具、UI、durable execution 与 memory，数据科学负责 eval、A/B 和错误分析。

新纪律来自能力和不可预测性的同时增长

LLM 已能承担多步工作，但开放输入和动态推理让观察、评价和改进成为核心工程活动。

这篇文章的论证链路

观察记录真实输入、输出、工具调用和上下文。
归纳把单次行为聚合成模式、失败类型或业务信号。
评价用 traces、datasets 或在线评分验证改动。
改进调整 prompt、工具、模型、memory 或 runtime。
