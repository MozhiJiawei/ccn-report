Why

电信客服需要在账单、激活、漫游和技术支持之间快速完成上下文判断，传统 chatbot 与人工多系统查询都难以兼顾规模和一致性。

What

Fastweb + Vodafone 用 LangGraph 和 LangSmith 建成两类 agent：面向客户的 Super TOBi，以及辅助坐席的 Super Agent。

How

Super TOBi 用 Supervisor 与 Use Case 图编排 guardrails、澄清、路由和 action tags；Super Agent 给坐席提供诊断、合规指引和可溯源解释。

Super TOBi 把对话和交易合在同一流程

Supervisor 负责入口、安全过滤和路由，Use Case agents 调用客户 API，并可返回 action tags 触发业务操作。

业务指标说明 agent 已进入高规模生产

文章给出近 950 万客户覆盖、90% correctness、82% resolution 和 5.2/7 CES 等信号。

Super Agent 把人类坐席变成更强入口

内部 agent 不直接对客户说话，而是为顾问提供即时诊断、来源依据和合规建议。
