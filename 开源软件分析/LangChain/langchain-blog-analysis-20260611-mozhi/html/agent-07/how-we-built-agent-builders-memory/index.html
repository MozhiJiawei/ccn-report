How we built Agent Builder’s memory system

Why

Agent Builder 面向重复执行同类工作的定制 agent，没有记忆会让用户跨会话反复解释偏好、规则和工具边界。

What

文章说明 Agent Builder 把记忆设计成文件系统形态，并用 AGENTS.md、skills、tools.json 和知识文件对应 procedural、semantic 等记忆类型。

How

底层并不使用真实文件系统，而是把文件存进 Postgres，再通过 Deep Agents 的 virtual filesystem 暴露给模型，让 agent 能读写记忆并在热路径中更新。

重复工作让记忆比通用聊天更必要

Agent Builder 的 agent 专门执行固定工作流，一个会话里的学习常常会直接影响下一次表现。

重复工作让记忆比通用聊天更必要

Agent Builder 的 agent 专门执行固定工作流，一个会话里的学习常常会直接影响下一次表现。

文件系统是给模型看的记忆界面

AGENTS.md 保存核心指令，skills 保存专门知识，tools.json 限定 MCP 工具集合，其他文件承载可更新知识。

数据库承载基础设施，filesystem 承载心智模型

Postgres 提供工程效率，Deep Agents 的 virtual filesystem 保留模型擅长读写文件的交互方式。
