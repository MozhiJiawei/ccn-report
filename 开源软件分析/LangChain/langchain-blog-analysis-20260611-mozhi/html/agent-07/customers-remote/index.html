How Remote uses LangChain and LangGraph to onboard thousands of customers with AI

Why：Remote 的客户入职涉及大型 HR、薪资和合规数据迁移，直接把 50MB Excel 或 SQL 导出塞进 LLM 会撞上上下文和幻觉风险。 What：Remote 在 AI Service 中构建 Code Execution Agent，把模型推理和确定性 Python 执行拆开，用于自动化客户数据迁移。 How：LangChain 负责工具调用和多模型抽象，LangGraph 表达节点与边的执行流，WebAssembly Python sandbox 运行 Pandas 转换并只把摘要回传给模型。

Why

Remote 的客户入职涉及大型 HR、薪资和合规数据迁移，直接把 50MB Excel 或 SQL 导出塞进 LLM 会撞上上下文和幻觉风险。

What

Remote 在 AI Service 中构建 Code Execution Agent，把模型推理和确定性 Python 执行拆开，用于自动化客户数据迁移。

How

LangChain 负责工具调用和多模型抽象，LangGraph 表达节点与边的执行流，WebAssembly Python sandbox 运行 Pandas 转换并只把摘要回传给模型。

大文件迁移不适合让模型直接读完

客户上传的 CSV、Excel 或 SQL 导出可能远超上下文窗口，也会让中间结果消耗大量 token。
