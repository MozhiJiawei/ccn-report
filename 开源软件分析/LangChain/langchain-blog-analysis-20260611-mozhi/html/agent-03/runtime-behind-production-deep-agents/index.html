The Runtime Behind Production Deep Agents

Why

Deep Agents 要从 demo 进入生产，瓶颈不只是模型能力，而是长时工作、并发工具、状态恢复和人类介入这些运行时问题。

What

文章把 production deep agents 的底座定义为 durable execution、streaming、human-in-the-loop、background execution 和可观测状态管理。

How

LangGraph runtime 通过持久化 checkpoint、interrupt/resume、并发控制、流式事件和状态图，把 agent 的长时运行变成可恢复、可检查的工程流程。

生产 runtime 的价值是让长时 agent 可恢复、可观察、可暂停。

Thesis

LangGraph runtime 把模型流、崩溃恢复、人工中断和记忆状态放进同一套执行语义。

Evidence

生产 runtime 的价值是让长时 agent 可恢复、可观察、可暂停。

模型流不是一次调用，而是可观察的工具闭环

model flow 图把 request、model、tools 和 result 串起来，说明 runtime 需要跟踪每次工具选择和返回，而不是只记录最终答案。

durable execution 把崩溃恢复变成运行时能力

crash recovery 图展示 worker A 失败后，worker B 能从持久化层恢复 c2 并继续执行 c3，说明 checkpoint 是生产 agent 的基础设施。

interrupt checkpoint 给人工介入留下明确位置

interrupt checkpoint 图把 review、edit action 和 continue 放在同一条状态线上，说明 human-in-the-loop 不是额外聊天，而是 runtime 的可恢复节点。

短期记忆和长期记忆都需要 runtime 管理

memory 图把 checkpoint 中的短期消息与长期 store 分开，说明 runtime 同时承担会话恢复和跨会话记忆读取。
