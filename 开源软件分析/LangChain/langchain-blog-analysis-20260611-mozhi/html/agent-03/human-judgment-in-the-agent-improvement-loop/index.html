Human judgment in the agent improvement loop

Why

Agent 失败往往不是简单的对错题，自动指标很难完整表达专家对质量、风险和业务语境的判断。

What

文章强调 human judgment 是 agent improvement loop 的核心输入：专家反馈需要被结构化，转化为 evals、数据集和可重复的改进信号。

How

LangSmith 通过人工标注、反馈、数据集管理和评估流程，把专家判断从一次性评论变成可反复运行的测试资产。
