Continual learning for AI agents

Agent 学习不只发生在模型权重里，还发生在 harness 和 context 里。

核心观点：Why: continual learning 不该只等同于更新模型权重，因为 agent 的行为还由运行框架和上下文共同决定。What: 文章把 agent 学习拆成 model、harness、context 三层，每层都有不同的改进对象和风险。How: 团队用 traces 驱动模型训练、harness 优化和 memory 更新，并按 agent、用户或组织层级管理 context。

文章的主张集中在这三点

这些子观点都服务于首屏结论，帮助读者快速抓住文章的判断框架。

01

模型层解决通用能力，但颗粒度最重

SFT、RL 等方法能改变权重，却面对灾难性遗忘，也通常服务整个 agent 系统，而不是每个用户的独立偏好。

02

Harness 层把运行日志变成框架改进

文章引用 Meta-Harness 的思路：先跑一组工作、评估结果、保存日志，再让 coding agent 根据 traces 修改 harness 代码。

03

Context 层更接近日常产品里的 memory

instructions、skills、tools 和长期记忆可以在 agent、用户、组织层更新，既能离线提炼，也能在执行过程中写入。

机制链路从这里读

文章不是平铺信息，而是在这条链路上说明产品、技术或组织变化。
