Introducing deploy cli

langgraph deploy 把 LangGraph agent 部署压缩成命令行一步。

核心观点：Why: agent 上线不该卡在手动搭 Docker 和基础设施。What: deploy cli 在 langgraph-cli 中提供 langgraph deploy、list、logs、delete 等命令。How: 它为本地 LangGraph 项目构建 Docker image，并配置 Postgres 持久化与 Redis streaming，方便接入 GitHub Actions、GitLab CI 或 Bitbucket Pipelines。

Whyagent 上线不该卡在手动搭 Docker 和基础设施。
Whatdeploy cli 在 langgraph-cli 中提供 langgraph deploy、list、logs、delete 等命令。
How它为本地 LangGraph 项目构建 Docker image，并配置 Postgres 持久化与 Redis streaming，方便接入 GitHub Actions、GitLab CI 或 Bitbucket Pipelines。

文章的主张集中在这三点

这些子观点都服务于首屏结论，帮助读者快速抓住文章的判断框架。

01

一条命令连接本地项目和 LangSmith Deployment

langgraph deploy 把本地 LangGraph 项目打包并部署到托管环境。

02

CLI 面向 CI/CD 工作流

文章点名 GitHub Actions、GitLab CI、Bitbucket Pipelines 等现有流水线。

03

管理命令覆盖上线后的基本操作

deploy list、deploy logs、deploy delete 让团队查看部署、读日志和删除实例。
