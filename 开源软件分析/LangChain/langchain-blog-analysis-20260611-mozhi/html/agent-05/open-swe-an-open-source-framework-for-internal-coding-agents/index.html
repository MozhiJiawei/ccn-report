Open SWE: An Open-Source Framework for Internal Coding Agents

Open SWE 把内部 coding agent 的生产模式做成可定制开源框架。

核心观点：Why: 多家公司内部 coding agent 已经收敛到相似生产架构，但每家从零搭建成本高。What: Open SWE 是基于 Deep Agents 和 LangGraph 的开源框架，复用 sandbox、curated tools、workflow invocation 和 orchestration 模式。How: 它用持久云 sandbox、AGENTS.md + source context、subagents、middleware safety nets，把 Slack、Linear 和 GitHub 请求变成可审查的 PR 工作流。

Why多家公司内部 coding agent 已经收敛到相似生产架构，但每家从零搭建成本高。

文章的主张集中在这三点

这些子观点都服务于首屏结论，帮助读者快速抓住文章的判断框架。

01

生产共性先于具体实现

文章总结 Stripe、Ramp、Coinbase 的共性：隔离 sandbox、精心维护工具、Slack-first、启动时 rich context、subagent orchestration。

02

Open SWE 选择组合而不是 fork

基于 Deep Agents 组合 harness，让 context management、planning、subagent 和 middleware 改进可持续流入。

03

确定性中间件补足 agent 弹性

message queue injection、open_pr_if_needed 和 ToolErrorMiddleware 处理需要稳定发生的步骤。
