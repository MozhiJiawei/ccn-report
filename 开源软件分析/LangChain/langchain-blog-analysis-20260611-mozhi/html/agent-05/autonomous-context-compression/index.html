Autonomous context compression

Deep Agents 让模型自己在合适时机触发 context compression。

核心观点：Why: 固定阈值压缩上下文会忽略工作节奏，可能在复杂工作中间发生。What: Deep Agents 增加 context compression tool，让模型在合适时机主动压缩自己的工作记忆。How: agent 在工作边界、提取结论后、读取大量新上下文前或进入多步流程前，把旧消息压成保留进度的 summary。

文章的主张集中在这三点

这些子观点都服务于首屏结论，帮助读者快速抓住文章的判断框架。

01

压缩时机比阈值更重要

deepagents 可按模型 profile 在 85% context limit 压缩，但文章认为好时机和坏时机差异很大。

02

工具化让模型接管一部分 harness 调参

用户不需要知道 context window，也不需要手动输入 /compact。

03

适用场景围绕工作边界和上下文更替

完成一个 deliverable、抽取研究结论、准备长草稿、开始 migration 或新需求推翻旧信息时都适合压缩。
