Introducing LangSmith Fetch: Debug agents from your terminal

Why: 调试 agent 时，工程师常在终端、代码和 LangSmith UI 之间来回切换，定位失败 trace 的上下文成本很高。 What: LangSmith Fetch 是一个终端工具，可以把 LangSmith trace、run、feedback 和相关上下文拉到本地，供开发者或编码 agent 直接查看和调试。 How: 它通过 CLI 接收 LangSmith 链接或标识符，下载结构化运行数据，并把失败路径、输入输出、工具调用和反馈转成适合命令行阅读的本地材料。

Why

调试 agent 时，工程师常在终端、代码和 LangSmith UI 之间来回切换，定位失败 trace 的上下文成本很高。

What

LangSmith Fetch 是一个终端工具，可以把 LangSmith trace、run、feedback 和相关上下文拉到本地，供开发者或编码 agent 直接查看和调试。

How

它通过 CLI 接收 LangSmith 链接或标识符，下载结构化运行数据，并把失败路径、输入输出、工具调用和反馈转成适合命令行阅读的本地材料。

命令行上下文更适合编码 agent 协助排障

当 trace 以文件或结构化文本落到本地，编码 agent 可以读取失败输入、工具调用和反馈，再回到代码里提出修复。

它补的是调试链路中的取证环节

LangSmith 仍负责记录和展示运行，Fetch 负责把某次失败的关键证据提取出来，减少从 UI 手动复制的摩擦。
