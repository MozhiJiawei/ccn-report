How agents can use filesystems for context engineering

Why: 长任务 agent 很快会遇到上下文窗口和状态管理问题；把所有信息塞进 prompt 会变得昂贵、混乱且难以复用。 What: 文章提出文件系统是 context engineering 的关键介质：agent 可以把计划、资料、记忆、中间产物和最终输出组织成可读写文件。 How: agent 通过目录结构、命名约定、读写工具和阶段性文件，把外部知识与任务进展持久化；后续步骤按需读取相关文件，而不是重新加载全部上下文。

Why

长任务 agent 很快会遇到上下文窗口和状态管理问题；把所有信息塞进 prompt 会变得昂贵、混乱且难以复用。

What

文章提出文件系统是 context engineering 的关键介质：agent 可以把计划、资料、记忆、中间产物和最终输出组织成可读写文件。

How

agent 通过目录结构、命名约定、读写工具和阶段性文件，把外部知识与任务进展持久化；后续步骤按需读取相关文件，而不是重新加载全部上下文。

文件系统给 agent 一个外部工作记忆

文章把 context engineering 从提示词技巧扩展到状态设计：让 agent 在文件里保存计划、发现和产物。

这种模式支持长任务的可审计性

文件记录了 agent 如何推进任务，也让人或另一个 agent 可以接手、检查和复用中间结果。
