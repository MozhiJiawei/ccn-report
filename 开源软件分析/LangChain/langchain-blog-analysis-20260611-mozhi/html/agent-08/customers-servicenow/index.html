Why

ServiceNow 的 customer success agents 进入真实客户流程后，团队需要知道 agent 在哪里成功、哪里失误以及哪些交互值得继续优化。

What

文章讲 ServiceNow 使用 LangSmith 为客户成功 agent 建立可见性，通过 trace 和评估理解运行行为。

How

LangSmith 记录 agent 输入、工具调用、输出和反馈，让团队可以复盘具体会话、聚合失败模式，并把这些观察转成改进动作。

可见性是客户成功 agent 进入生产的前提

ServiceNow 的问题不是是否能做一个 agent，而是当 agent 面向客户工作时，团队能否解释和改进它的行为。

Trace 把一次会话拆成可复盘证据

LangSmith 记录每个步骤，使团队能看到模型回答、工具调用、延迟和错误，而不是只看最终文本。
