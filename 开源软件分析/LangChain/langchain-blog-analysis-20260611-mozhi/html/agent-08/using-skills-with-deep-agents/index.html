Why

Deep Agents 面对复杂任务时不能只靠一段系统提示词，需要把可复用流程、领域知识和工具使用方法封装成可调用能力。

What

文章说明 skills 如何扩展 Deep Agents：skill 是一组指令、脚本和资源，agent 可在需要时加载，从而获得特定工作流能力。

How

做法是把技能说明写成结构化文件，配套脚本和资产放在技能目录中；agent 根据任务选择相关 skill，读取说明后执行其中定义的流程。
