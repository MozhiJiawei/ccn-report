LangSmith Agent Builder now in Public Beta

Why: 很多团队知道要做 agent，却卡在提示词、工具、子任务和部署形态的初始搭建上，原型到可运行应用之间仍有大量手工编排。 What: LangSmith Agent Builder 进入 Public Beta，提供无代码方式创建、测试和迭代 agent，并把自然语言需求转成可运行的 agent 配置。 How: 产品用对话式构建、工具选择、内置测试和 LangSmith trace 连接构建流程，让用户能在同一个界面里描述目标、运行样例、观察行为并继续调整。

Why

很多团队知道要做 agent，却卡在提示词、工具、子任务和部署形态的初始搭建上，原型到可运行应用之间仍有大量手工编排。

What

LangSmith Agent Builder 进入 Public Beta，提供无代码方式创建、测试和迭代 agent，并把自然语言需求转成可运行的 agent 配置。

How

产品用对话式构建、工具选择、内置测试和 LangSmith trace 连接构建流程，让用户能在同一个界面里描述目标、运行样例、观察行为并继续调整。

Public Beta 的信号是 Agent Builder 进入更广泛试用

这不是只给内部团队的实验入口，而是面向更多用户开放的 agent 创建界面。
