Execute Code with Sandboxes for Deep Agents

Why: Deep Agents 若要完成数据处理、文件转换或代码验证，需要执行代码；但直接在宿主环境运行会带来安全和可复现风险。 What: 文章介绍如何为 Deep Agents 接入 sandboxes，让 agent 在隔离环境中运行代码、读写文件和验证结果。 How: 实现上把代码执行封装成工具，由 sandbox 提供临时文件系统、依赖安装和命令执行边界；agent 通过工具请求执行，宿主侧控制权限与生命周期。

Why

Deep Agents 若要完成数据处理、文件转换或代码验证，需要执行代码；但直接在宿主环境运行会带来安全和可复现风险。

What

文章介绍如何为 Deep Agents 接入 sandboxes，让 agent 在隔离环境中运行代码、读写文件和验证结果。

How

实现上把代码执行封装成工具，由 sandbox 提供临时文件系统、依赖安装和命令执行边界；agent 通过工具请求执行，宿主侧控制权限与生命周期。

代码执行让 agent 从回答问题变成验证结果

能运行代码后，agent 可以计算、解析文件、跑测试或检查生成物，减少只靠语言推断的风险。

代码执行让 agent 从回答问题变成验证结果

能运行代码后，agent 可以计算、解析文件、跑测试或检查生成物，减少只靠语言推断的风险。

Sandbox 是能力边界，不只是基础设施

隔离环境限制文件系统和网络影响，允许每次任务从干净状态开始，降低执行未知代码的风险。

Deep Agents 通过工具接口接入执行环境

agent 不直接拥有宿主机权限，而是调用受控工具提交代码或命令，sandbox 返回输出、错误和文件变化。
