Why Model Neutrality Matters More Than Cloud Neutrality

Why：模型本身变化太快，把业务逻辑交给单一厂商 harness 会把迁移成本压到最难拆的层。What：文章认为 token 会继续商品化，真正的锁定发生在 agent 编排与工具层；中立 harness 需要开源、多模型、并理解不同模型 profile。How：它借 Terraform 对抗云工具锁定的历史，推导出 agent 运行中也要能按步骤切换 Claude、GPT、Gemini、Llama 或自托管模型。

Why

模型本身变化太快，把业务逻辑交给单一厂商 harness 会把迁移成本压到最难拆的层。

What

文章把模型时代类比云时代：token 正在商品化，真正的锁定发生在编排、工具、记忆和业务逻辑所在的 harness 层；中立 harness 需要开源、多模型、并保留模型 profile 差异。

How

它借 Terraform 对抗云工具锁定的历史，推导出 agent 运行中也要能按步骤切换 Claude、GPT、Gemini、Llama 或自托管模型。

锁定不在商品本身，而在围绕商品的工具层。

云时代里 compute、storage、network 越像商品，厂商越会在 CloudFormation、ARM、Vertex 这类工具层制造迁移成本。文章认为模型实验室正在对 agent harness 重复同一动作。

模型中立比云中立更频繁地被使用。

云迁移通常发生在合约期或故障时；模型能力和价格却按月、按季度变化。一个生产 agent 可能在单次运行里把 coding、multimodal、低成本步骤路由给不同模型。

中立 harness 不是把模型抹平。

文章提出的中立 harness 是 open source、multi-model out of the box、profile-aware：既能切换供应商，又保留每个模型的提示、工具调用和能力差异。
