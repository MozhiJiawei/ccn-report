From Token Streams to Agent Streams

Why：graph-shaped agent 的运行过程包含工具、subagent、状态、审批和媒体，token delta stream 不再够用。What：新 streaming 模型把输出组织成 typed events、channels、namespaces、projections 和 scoped subscriptions。How：应用订阅自己渲染的 projection，运行时负责组装、排序、重连和 replay；同一协议覆盖本地/远程运行及 React、Vue、Svelte、Angular SDK。

Why

graph-shaped agent 的运行过程包含工具、subagent、状态、审批和媒体，token delta stream 不再够用。

What

新 streaming 模型把输出组织成 typed events、channels、namespaces、projections 和 scoped subscriptions。

How

应用订阅自己渲染的 projection，运行时负责组装、排序、重连和 replay；同一协议覆盖本地/远程运行及 React、Vue、Svelte、Angular SDK。

事件需要同时说明“是什么”和“从哪里来”。

channels 描述 message、values、updates、tools、lifecycle、checkpoints、custom 等 concern；namespaces 标记 root graph、nested subgraph 或 Deep Agents subagent。两者分离是协议核心。

projection 把底层 stream 变成应用 API。

前端不需要自己拼接 raw chunks，而是读取 messages、tool calls、subagent statuses 或 custom channels。reasoning、tool-call arguments、usage、multimodal blocks 都保留结构。

scoped subscription 让复杂 UI 不被全量 token 拖垮。

subagent inspector 只订阅当前打开的 subagent；dashboard 只看高层 lifecycle；浏览器刷新后可从上次位置 reattach 到还在运行的 thread。

自定义 channel 让产品状态也能实时流动。

streaming transformers 可从原始事件派生 tool activity、citations、progress、A2UI、media handles 等 extension；storybook demo 说明文本、图片、音频和视频可共享同一架构。
