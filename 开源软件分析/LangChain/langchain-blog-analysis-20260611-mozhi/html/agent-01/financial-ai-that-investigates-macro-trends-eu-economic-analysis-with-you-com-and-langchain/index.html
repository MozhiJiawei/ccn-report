Why

宏观金融研究既要全域数据覆盖，又要深挖异常国家和保留审计链；把所有问题塞进一个大查询会稀释检索预算。

What

文章展示 EU 2025 GDP 研究 agent，用 You.com Finance Research API、Deep Agents 和 LangSmith 生成带 citations、workpapers 和最终报告的分析。

How

orchestrator 把 Shape A 数据表、异常检测、分解和 country investigation 分给多个 subagent，并用 LangSmith trace 把每个结论追溯到 API call 与来源 URL。

预算模型决定了 query shape。

Finance Research API 每次调用有有限 compute 和 retrieval budget。文章把查询分成 Shape A 数据表、Shape B 单国解释、Shape C 机制比较，避免多国多维度解释把预算摊薄。

subagent 分层让宽覆盖和深调查同时存在。

landscape scanner 取 27 个 EU 成员国数据，anomaly analyst 计算均值并标出偏离 2 个百分点以上国家，decomposers 并行补充支出和行业分解，country investigators 聚焦异常国家。

文件系统 workpapers 控制上下文膨胀。

CompositeBackend 把 agent 内部状态和文件写入分开；subagents 把 landscape_scan、anomaly_analysis、country workpapers 写入文件，orchestrator 读回后合成 final_report。

观察性是金融场景的结果的一部分。

完整运行约 45 分钟、约 20 次 API calls。每个 you_finance_research 调用、内置工具调用和 orchestrator 决策都被 LangSmith 捕获，最终 claim 可回溯到具体工具调用和来源。
