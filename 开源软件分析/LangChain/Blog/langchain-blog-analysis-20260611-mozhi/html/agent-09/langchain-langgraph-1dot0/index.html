LangChain and LangGraph Agent Frameworks Reach v1.0 Milestones

Why: agent 开发进入生产阶段后，核心框架需要稳定 API、清晰文档和长期兼容承诺。
What: LangChain 与 LangGraph 达到 v1.0 里程碑，标志着 agent framework 与 runtime 的基础层趋于稳定。
How: 通过整理核心 abstractions、文档、迁移路径和生产能力，团队把早期快速迭代的接口固化为更可靠的构建基础。

v1.0 的意义是降低生产采用的不确定性

LangChain 与 LangGraph 分别稳定开发层和运行层

前者帮助快速构建 agent，后者处理状态图、持久执行、流式输出和人工介入等生产运行问题。
