Introducing LangSmith Fleet

Fleet 把自然语言创建 agent 扩展成企业级 agent 管理工作区。

核心观点：Why: 自然语言创建 agent 降低了门槛，也把治理焦点推到分享、凭证和审计。What: LangSmith Fleet 是企业工作区，用来创建、使用和管理一组带 memory、tools、skills 和 channel 的 agents。How: 它用 clone/run/edit 权限、Claw/Assistant 凭证模型、Slack bot identity、Inbox 审批和 tracing 形成管理闭环。

How它用 clone/run/edit 权限、Claw/Assistant 凭证模型、Slack bot identity、Inbox 审批和 tracing 形成管理闭环。

从建 agent 转向管 fleet

文章指出创建门槛下降后，组织需要回答 owner、auth、audit 和 secure sharing。

02

权限模型覆盖复用与控制

can clone、can run、can edit 让中央团队发布 agent，同时控制谁能修改配置。

03

身份、审批和 trace 形成审计链

每个 agent 可有独立 Slack bot，Inbox 处理审批，tracing 记录工具调用、决策和数据访问。
