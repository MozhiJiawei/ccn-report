Polly is generally available everywhere you work in LangSmith

Polly 从局部助手升级为贯穿 LangSmith 工作流的 agent debugging teammate。

核心观点：Why: agent 调试的难点是失败原因藏在很长的 trace、prompt 和 conversation 中。What: Polly GA 后出现在 LangSmith 所有页面，能保持跨页面上下文并直接采取行动。How: 它读取 trace/thread/experiment/evaluator 的当前上下文，帮助定位失败、写评估器、比较实验和修改 prompt。
