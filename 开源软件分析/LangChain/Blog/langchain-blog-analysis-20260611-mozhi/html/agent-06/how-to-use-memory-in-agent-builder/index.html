薄观点文 / how-to · February 19, 2026 · 4 min

WhyAgent Builder 的记忆会随着反馈变好，但用户需要理解怎样把短期对话沉淀成长期行为。
What文章给出三种用法：让 agent 记住有效做法、用 skills 承载专门上下文、直接查看和编辑记忆文件。
How短期文件只存在当前 thread，长期文件保存在 `/memories/`；agent 会把明确反馈写入 markdown 指令或按主题创建 skill，并在保存前请求用户确认。

记忆本质上是 agent 可读写的文件

文章先把抽象概念降到一个简单模型：短期 memory 包含计划、工具输出和进度，只存在当前 thread；长期 memory 是持久 markdown 文件，包括核心指令和 skills。

显式反馈帮助 agent 把经验固化下来

当用户说某种格式有效、偏好 bullet points，或让 agent 整理本次经验时，agent 会把这些内容转写到长期指令中。隐含经验不够明确时，直接说 remember 最有价值。

Skills 让专门上下文按需加载

文章用写作 agent 举例：voice 和 style 放在核心指令里，LangSmith Deployment、Agent Builder 等产品知识放到各自 skill 中，任务相关时再加载，避免把所有上下文一次塞进模型。

直接编辑适合小而精确的改动

用户可以打开记忆文件检查 agent 如何理解任务，也可以直接修改调度时间或一行指令。文章把这种能力描述为快速校准 agent 思路的方式。
