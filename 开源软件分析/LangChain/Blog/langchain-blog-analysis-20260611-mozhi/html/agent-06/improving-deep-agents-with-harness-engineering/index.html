Why模型能力很强但输出尖峰明显，agent 质量常由 prompt、tools、middleware 等 harness 决定。
WhatLangChain 在模型固定为 gpt-5.2-codex 的情况下，仅通过 harness engineering 让 deepagents-cli 在 Terminal Bench 2.0 从 52.8 提升到 66.5。
How他们用 LangSmith traces 做失败分析，围绕 self-verification、环境上下文注入、loop detection 和 reasoning budget 调整迭代。

Traces 让失败分析变成可重复流程

团队把 trace analysis 做成 Agent Skill：从 LangSmith 拉实验 traces，派生并行错误分析 agent，再由主 agent 综合失败模式和修改建议。这个外循环像 boosting，专门盯前一轮做错的样本。

Self-verification 是最大质量杠杆之一

常见失败是 agent 写完代码、看一眼自己的代码就停止。LangChain 通过系统提示和 PreCompletionChecklistMiddleware 强制 planning、build、verify、fix，要求 agent 跑测试、读完整输出，并对照 task spec 而不是自己的实现。

环境上下文减少 agent 在陌生目录中的搜索错误

LocalContextMiddleware 在启动时注入 cwd、父子目录、Python 安装等 tooling 信息；prompt 还强调自动评分、路径精确性和 edge cases，让 agent 写出可被 programmatic tests 检查的代码。

Reasoning budget 需要按阶段分配

Terminal Bench 有 timeout，全部使用 xhigh reasoning 会因耗时表现差，只有 53.9%；high 为 63.6%。团队最终采用 xhigh-high-xhigh 的 reasoning sandwich，让 planning 和 verification 花更多推理，implementation 控制成本。
