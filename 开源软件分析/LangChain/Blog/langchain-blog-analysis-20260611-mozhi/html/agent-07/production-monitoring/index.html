Why

传统监控假设输入和代码路径相对固定，但 agent 面对自然语言、非确定性模型和多步工具调用，上线后才会暴露真实行为。

What

文章认为生产监控需要从 latency、error rate 扩展到输入、输出、推理轨迹、工具选择、用户反馈和质量变化。

How

用 LangSmith traces 捕获自然语言交互和工具链路，再把生产数据聚合为在线评价、失败模式、数据集和持续改进信号。

agent 的输入空间无法像表单一样枚举

同一退款、账单或技术支持意图会被用户用无数种说法表达，测试集很难覆盖全部路径。

agent 的输入空间无法像表单一样枚举

同一退款、账单或技术支持意图会被用户用无数种说法表达，测试集很难覆盖全部路径。

质量监控要看对话本身

APM 指标只能说明系统慢了或错了，agent observability 还要记录输入、输出、检索、工具调用和 reasoning。

生产数据是持续改进的燃料

上线 traces 可以被打标、聚类、评分并沉淀成 eval 数据集，让监控和改进形成闭环。

这篇文章的论证链路

观察记录真实输入、输出、工具调用和上下文。
归纳把单次行为聚合成模式、失败类型或业务信号。
评价用 traces、datasets 或在线评分验证改动。
改进调整 prompt、工具、模型、memory 或 runtime。
