Why

很多团队知道想自动化什么，却不想从空白 prompt 开始连接工具、写指令和调试流程。

What

Agent Builder Template Library 提供可部署、可定制的预置 agent，并通过 Tavily、PagerDuty、Exa、Box、Arcade 等伙伴覆盖常见工作。

How

模板内置工具连接和 agent instructions，用户可修改指令、增加工具、设置审批，并通过 Arcade MCP Gateway 扩展到 8,000 个工具。

模板把想法直接推进到可运行 agent

Calendar Brief、Email Assistant、Incident Responder、Document Intake、Talent Sourcing 等模板覆盖日常业务场景。

模型与工具选择保持开放

Agent Builder 支持 OpenAI、Anthropic、Google Gemini，以及符合 OpenAI 或 Anthropic 规格的自定义和开源模型。
