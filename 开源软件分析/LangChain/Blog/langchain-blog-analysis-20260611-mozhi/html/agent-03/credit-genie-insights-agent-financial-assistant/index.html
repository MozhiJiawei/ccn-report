How Credit Genie used Insights Agent to improve their AI financial assistant

Why

Credit Genie 的 AI 金融助手已经在生产中服务用户，但团队需要知道失败集中在哪里，才能把客服压力和用户困惑转成可修复的产品问题。

What

Insights Agent 从 LangSmith 轨迹中发现 36% 客服请求来自同一类产品缺口，让团队把模糊反馈变成具体改进机会。

How

Credit Genie 用 LangSmith 收集运行轨迹，再让 Insights Agent 聚类、解释和定位失败模式，帮助团队优先处理高频问题。

Thesis

这篇案例的价值在于把海量对话里的失败模式聚成清晰优先级。

Evidence

Insights Agent 把 36% 客服缺口变成可修复的产品信号。

失败归因从人工抽样变成规模化分析

生产对话多到无法逐条阅读时，团队容易只看到零散投诉。文章展示的是用 agent 阅读轨迹、归纳模式，把客服问题变成产品和 agent 改进队列。

36% 信号让优先级变得明确

Insights Agent 发现 36% 的客服请求来自同一类产品缺口，这个数字让团队能判断影响范围，并把修复重点放在真正高频的失败原因上。

LangSmith 的轨迹是分析原料

没有完整 trace，Insights Agent 就只能看最终答案。LangSmith 记录用户输入、agent 行为和输出，让聚类和根因分析能回到具体运行过程。
