Deep Agents v0.6 把 code interpreter、harness profiles、streaming v3、DeltaChannel 和 ContextHubBackend 打包成同一条性能主线。

01问题

长流程 agent 的瓶颈已经不只是模型答案质量，而是模型成本、上下文膨胀、检查点存储和前端可观测性一起限制生产化。

02观点

Deep Agents v0.6 把 code interpreter、harness profiles、streaming v3、DeltaChannel 和 ContextHubBackend 打包成同一条性能主线。

03机制

它让工具调用在运行时中完成、按模型版本化调优 harness、用类型化事件流暴露进度、用 diff 存检查点，并把 agent 行为文件放进可版本化的 Context Hub。
