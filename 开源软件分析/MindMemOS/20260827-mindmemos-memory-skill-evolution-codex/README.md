# MindMemOS：可迁移、自演化的 Agent 记忆操作层

## 一句话总结

MindMemOS 是 2026 年 8 月 12 日发布并开源的可迁移 Agent 记忆操作层，它以实体、属性和时间组织持久记忆，通过 Compact Search、Dreaming、Feedback、Schema 演化与 MindSkillEvolve 把任务轨迹转为版本化 Skill，在作者报告的 LOCOMO 评测中达到 94.03% 准确率、在 SpreadsheetBench 监督 Skill 演化中相对初始 Skill 提高 9.2 个百分点，用于让长期记忆可检索、可纠错、可追溯并持续沉淀为能力。
