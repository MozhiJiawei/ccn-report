# Gemini-3.8-Flash-TTS

## 一句话总结

Google 于2026年9月23日发布的 Gemini 3.8 Flash TTS 与 Flash-Lite TTS 是面向声音设计、表演控制和规模化语音生成的文本转语音模型，其中 Flash TTS 在发布时引用的 Hume 声音设计评测中取得71.4分，可帮助开发者按角色、口音与情绪生成语音。
