# Nemotron-3.5-Transcribe

## 一句话总结

NVIDIA于2026年10月28日发布的Nemotron 3.5 Transcribe是面向录音处理的开放权重话音模型，支持40种语言转录、31种语言与英语互译和13种语言的说话人归属，并配套覆盖48种语言、463,062小时源语音的Granary v2标签清单及数据整理流水线，用于构建可提示控制和领域适配的离线语音工作流。
