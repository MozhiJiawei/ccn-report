01 / Executive conclusionXeon 6 + AMX on HGX B200

Xeon 6 + AMX 不是替代 B200/GB200，而是把已供电的 host CPU 变成 CPU 8B endpoint

在 HGX B200 系统里，GPU 继续跑 405B 生成；CPU 8B endpoint 吸收轻任务、校验、路由和短推理并发。公开结果的正确读法是 endpoint-level serving benchmark，不是完整 multi-agent app 端到端 benchmark。

CPU model allowed to contend across all CPUs without binding: 56 → 51 supported CPU users.

适合：mixed LLM/SLM、multi-agent、semantic routing，把轻任务交给 CPU 8B。
不适合：所有请求都必须交给 405B，或把 CPU 当作 GPU 大模型算力替代品。
Why uplift exists405B GPU service 只占用少量 host CPU，剩余 Xeon cores 可服务 8B endpoint。
What changes总并发 = GPU 127 + CPU 56；不是 GPU 405B 单 endpoint 变快。
Deployment caveatNUMA-aware CPU binding / OpenMP tuning 是保住 CPU 端收益的部署条件。
[2] Supermicro XML: GPU-only 127; remaining Xeon cores add 56 CPU users, total 183, up to 1.44x; no binding drops 56 to 51.Correct takeaway: reuse host CPU slack for SLM endpoints; do not claim CPU replaces GPU large-model compute.
