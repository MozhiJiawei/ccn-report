# HCL-受保护持续演化

## 一句话总结

2026年8月19日发布的arXiv v1论文提出的HCL是一种在冻结基础模型参数时联合演化接口、记忆、技能与路由的智能体持续学习框架，通过当前收益、历史锚点保留及有效性三重检查后才提交候选状态，在论文四任务文本预算扫描中将最终均分从无历史约束的60.13%提高至63.46%、平均遗忘从3.45降至1.22个百分点，但不保证锚点之外零遗忘。
