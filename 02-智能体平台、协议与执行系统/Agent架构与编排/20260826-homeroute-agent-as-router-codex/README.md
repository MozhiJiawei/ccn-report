# 家庭路由系统：自适应选路（HomeRoute）

截至 2026-08-26，本报告参考 Agent-as-a-Router 研究（arXiv:2606.22902v3）提出家庭智能体模型调度方案；论文在约一万个代码任务上报告，其自适应路由器的平均综合表现为 49.98%，高于始终使用最强模型方案的 43.83%；本方案据此在任务开始前选择合适的模型和工具，在任务结束后检查完成度与风险，并记录执行反馈，供团队用四周概念验证评估能否以更低模型成本维持或提高一次完成率。

## 场景问题

家庭智能体处理简单任务时也经常调用最强模型，导致推理用量费用高、等待时间长，还可能选错工具或错误执行高风险动作。如果能把简单任务交给更便宜、更快的处理路径，同时保证复杂任务和敏感操作的质量，就能降低每个活跃家庭的服务成本，并通过更高的任务完成率和更可信的执行改善活跃度、留存和合作伙伴接入。

## 方案描述

HomeRoute 面向家庭智能体产品和平台团队。它设置两道关口：第一道在任务开始前判断任务难度、风险和所需工具，选择规则、轻量模型或强模型；第二道在执行结束后检查用户目标是否真的完成、是否存在安全风险。系统还会记录成功、失败和用户反馈，逐步改进后续选择。试点目标是把推理用量成本降低 25%–40%、95% 请求的响应时间上限降低 20%–35%，并将一次完成率提高 8–15 个百分点。
