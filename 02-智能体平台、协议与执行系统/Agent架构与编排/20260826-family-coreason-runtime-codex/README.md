# 家庭端云协同运行系统（Family-CoReason Runtime）

截至 2026-08-26，本报告参考端侧与云端大模型协同推理论文（arXiv:2509.24050v4）提出一套家庭智能体运行方案；论文实验中，Qwen2.5-1.5B 在最多 30% 的任务主动求助云端时取得 66.7% 的平均准确率，比传统路由方案高 5.9 个百分点；本方案据此让本地模型先处理任务、只在确有收益时求助云端，并在执行工具前后进行安全检查，供家庭人工智能平台用 8–10 周试点验证能否减少云端调用和等待时间并提高任务完成率。

## 场景问题

家庭智能体在多步骤任务中经常默认调用云端大模型。随着对话越来越长，推理用量、费用和等待时间会不断增加；同时，接口返回成功并不代表用户的目标已经完成，门锁、支付等敏感操作也可能缺少执行前检查。这些问题会压缩免费服务额度，降低用户活跃度和任务成功率，也让敏感场景难以商业化。

## 方案描述

“家庭端云协同运行系统”面向家庭人工智能平台及其现有智能体框架。高频、低风险且规则明确的任务直接调用本地工具；参数规模约 10 亿至 30 亿的本地模型先自行处理较复杂任务，只有在预计云端模型能明显改善结果且预算允许时才发起求助；安全守门模块则在工具执行前检查风险，在执行后确认用户目标是否完成。试点目标是把云端调用率降低 50% 以上、云端推理用量成本降低 40% 以上、95% 请求的响应时间上限降低 35% 以上，并将任务完成率提高 8–12 个百分点。
