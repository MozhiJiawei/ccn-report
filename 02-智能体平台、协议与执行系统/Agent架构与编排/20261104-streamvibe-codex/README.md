# StreamVibe

## 一句话总结

StreamVibe是Google等于2026年10月发布的主动视频Agent研究系统，通过StreamVibe-VL与维护意图生命周期和任务进度的Harness协同，在4,100条覆盖显式、隐式和动态意图的评测样本中验证持续视频交互的帮助时机与内容质量。
