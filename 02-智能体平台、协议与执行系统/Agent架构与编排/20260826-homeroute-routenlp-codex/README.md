# 家庭路由系统：分层模型调度（HomeRoute）

截至 2026-08-26，本报告参考 RouteNLP 研究（arXiv:2604.23577）提出家庭智能体任务调度方案；论文在持续 8 周、约 5000 次请求的在线客服试点中报告，系统质量达到基准方案的 97.1%，超时或服务不达标的比例为 2.3%，不同任务的成本降低约 40%–85%；本方案据此按照任务风险和难度选择处理路径，并增加执行保护、结果验收和失败复盘，供团队用 8 周可随时回退的试点验证能否降低成本且不降低质量。

## 场景问题

家庭智能体常常用同一套多轮大模型流程处理所有任务。简单任务因此付出不必要的推理费用和等待时间，复杂任务又可能因为信息不足或工具失败而需要反复重试；高风险操作如果没有执行前检查，任务结束后又没有完成证据，系统就难以规模化商用，也会影响用户留存和付费意愿。

## 方案描述

HomeRoute 面向家庭智能体平台团队。系统先把用户意图、权限、可用工具、预算和完成条件整理成统一任务说明，再根据风险和难度选择固定规则、轻量模型或强模型；当结果把握不足时自动升级到更强路径，工具执行前检查权限和风险，执行后通过设备状态与业务结果确认任务是否完成，并集中复盘最常见、代价最高的失败。首期目标是让 60%–75% 的低风险请求走快速或轻量模型路径，推理成本降低 40%–60%，最慢的 1% 简单任务响应时间至少降低 60%，一次完成率提高 8–12 个百分点，并让所有高风险调用都经过策略审查。
