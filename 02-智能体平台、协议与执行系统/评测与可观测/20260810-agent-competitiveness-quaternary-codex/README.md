# 智能应用竞争力四元分类

截至 2026-08-10，本报告基于 WAIC 2026 TOP200 已爬取材料中的 4 个典型 Agent 案例，将智能应用的客户可见竞争力定义为泛化性、任务闭环率、时延和成本四个一级维度，并通过独立视觉 QA 验证滚动式 HTML 及 4 个子报告的离线阅读与跳转完整性。

## 归档内容

- `index.html`：四元分类滚动式主报告。
- `vendors/v0183/report.html`：它石智航 AWE 3.5 + A1，泛化性案例。
- `vendors/v0022/report.html`：EasyLink 投行合规智能体，任务闭环率案例。
- `vendors/v0456/report.html`：超维动力 KAIBot + SMASH，时延案例。
- `vendors/v0045/report.html`：MulanAI 视频营销 Agent，成本案例。

## 证据边界

“TOP1”表示基于产品任务机制与客户购买逻辑形成的分析判断，不是公开性能数据推导出的厂商排名；案例只使用 2026 年官方信息或 WAIC 2026 相关报道，厂商披露但缺少样本、基线或独立复测的指标均在报告中明确标注。
