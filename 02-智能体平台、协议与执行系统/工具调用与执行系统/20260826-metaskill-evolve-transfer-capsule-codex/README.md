# MetaSkill-Evolve：让 Agent 学会改进自己的改进方法

## 一句话总结

MetaSkill-Evolve 不仅让 Agent 学习完成任务的技巧，还让它学习“怎样总结和改进技巧”；在 2026 年 7 月 6 日发布的论文初版中，这种方法把 OfficeQA 的测试成绩从 31.8 提高到 55.3、SealQA 从 29.2 提高到 45.3、ALFWorld 从 92.3 提高到 94.2。

## 它解决什么问题

常见的自我改进方案只会回放过去的记录，或者反复修改当前任务的提示词。这些变化很容易只适用于眼前任务，而且很难回答三个关键问题：为什么要这样改、什么任务可以复用、出现副作用后怎样恢复。

## 方案怎么做

这份报告提出“元技能迁移包”。系统有两个学习节奏：快循环负责改进具体任务技能，慢循环负责改进分析失败、查找经验、分配资源和提出修改方案的方法。只有通过新任务验证的结果，才会连同适用范围、版本来源、验证证据和撤回方法一起封装，供其他任务安装使用。

业务试点建议先在小流量中观察，再逐步放大使用范围。目标是比直接复用历史记录多提高 5 至 10 个百分点的成功率，减少 30% 的人工调试次数、25% 的新场景交付周期和 20% 的重复失败输入，同时把误用经验造成的负面影响控制在 3% 以内。这些是待验证的业务目标，不是论文已经证明的产品效果。
