# VoxMem

## 一句话总结

墨尔本大学与新南威尔士大学于2026年9月发布VoxMem，以4类声学证据和4种记忆操作构成15类任务，在799道问题的8K至64K历史上形成3196个实例，测得15个音频语言模型在32K下最高总体准确率仅38.5%，用于诊断跨会话语音记忆缺口。
